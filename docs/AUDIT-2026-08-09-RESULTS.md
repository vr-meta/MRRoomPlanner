## Что исправлено

### WP1 — единый владелец времени жизни (краш Undo) ✅
- `ISelectable.IsAlive` — проверка живости вместо `!= null` (перегруженный `==` Unity не
  работает через интерфейсные ссылки; уничтоженный компонент проходил проверку).
- `EditHistory` exception-safe: `Peek → вызов → Pop`; упавший `Do()` не попадает в историю;
  добавлен `PurgeWhere`.
- Все пользовательские удаления — через `DeleteCommand` (скрытие, отменяемо); жёсткий
  `Destroy` только для заготовок и вытеснения по лимиту, всегда через `Unregister`.
- `SceneModel.Unregister` вычищает команды удалённого объекта из обоих стеков;
  `Selectable.OnDestroy` — страховочный авто-Unregister через `SceneModel.Instance`.
- Скрытые объекты не магнитят снапы, не считаются в лимите, не «удаляются повторно».
- Регрессия: `Undo_AfterTargetDestroyed_IsSafeNoOp`, `Unregister_PurgesTargetCommandsFromHistory`.

### WP2 — ориентация треугольников ✅
- `Floor`: все 6 граней наружу (верх был вниз — пик сверху занижался на толщину плиты).
- `Wall`: winding не зависит от стороны interior (глобальный флип при `oSign < 0`).
- Тесты на знак нормали каждой грани (обе стороны interior); допуски Play-тестов ужесточены
  до точной грани (`y = 0 ± 0.01` вместо маскирующего `InRange(-0.25, 0.05)`).

### WP3 — производительность (Quest 72–120 Гц) ✅
- Драг: transform-превью каждый кадр + ОДНА параметрическая пересборка (и перепекание
  MeshCollider) на отпускании.
- `Physics.RaycastNonAlloc` с кэшированным буфером в `SceneModel.TryPick`.
- Лейбл измерения: обновление и `ForceMeshUpdate` только при смене округлённых см.
- Утечки закрыты: текстура плана (`Destroy` старой при перезагрузке), меши Wall/Floor
  (`OnDestroy`), кэш рендереров маркеров (было ~80 `GetComponent`/кадр).

### WP4 — ввод и UX ✅
- Фоны панелей несут коллайдеры; `overMenu` = любой хит слоя 2 → клик сквозь панель невозможен.
- Драг завершается и записывается при блокировке меню и смене инструмента (нет неучтённого
  дрейфа); undo/redo подавлены во время драга; мёртвая зона курсора устранена
  (`_lastCursor` только от реального пересечения плоскости).
- Захват инспектора — только по свежему нажатию грипа над тайтл-баром.
- Коллайдеры точек измерения восстанавливаются при деактивации; хаптика гасится в `OnDisable`;
  тинт выделения красит и TMP-бейдж (`_FaceColor`).

### WP5 — устойчивость геометрии ✅
- Miter limit (×4 от офсета) — нет «шипов» на острых разворотах.
- Схлопывание дублей соседних точек (дабл-клик в MR), фолбэк нормали на развороте ~180°.
- Отрицательные thickness/height нормализуются; `planScale`: ноль → 1, отрицательный —
  легитимное зеркало.
- `Build` защищён от null и алиасинга собственного списка точек; `RayPlaneY` принимает
  луч, стартующий на плоскости.
- Новое покрытие: Bevel-стык, Inner-офсет, UV пола по мировым координатам, `Record`
  очищает redo, LIFO, `Clear`, вырожденные входы математики.

### WP6 — границы сборок ✅
- `RoomPlanner.App.asmdef` (весь рантайм) + `RoomPlanner.Editor.asmdef` (тулинг).
- Play-тесты гоняют реальный `Selectable` — рукописный дубль `GeoProbe` удалён.
  (`FakeSelectable` оставлен сознательно: тесты модели без геометрии.)
