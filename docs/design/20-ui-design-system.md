# 20 — UI Design System: радиальное меню, виджеты, иконки 🔜

Единый дизайн-код меню и панелей. Итог двух экспертных панелей 2026-08-10
(VR-эргономика · game-UI/Rust/Alyx · pro-CAD workflow; дизайн-системы · иконки ·
real-time графика). Обновляет и дополняет [16-ux-v2](16-ux-v2.md): принятые там
решения (palm-gating, lazy-follow, «яркость = состояние, hue = слой», углы
типографики, numpad, stick-scrub) сохраняются; что пересмотрено — помечено.

**Сквозной принцип UI тот же, что и у геометрии:** всё процедурно. Иконки — SVG-пути
**текстом в коде**, тесселируются в меши через `Polygon.TriangulateWithHoles`
(ear clipping с дырами уже в Core). Ни одного бинарного ассета.

---

## 1. Радиальное меню (переключение инструментов)

Назначение: радиал — **переключатель инструментов**. Контекстные операции выбранного
объекта (Delete/Duplicate/Flip/Join) — второй инстанс того же компонента на A-hold
(как принято в 16 P2.2). Вложенных радиалов **нет и не будет** — один уровень.

### Вызов и механика

- **Клик ЛЕВОГО стика (tap)** — открыть. R3 остаётся «предыдущий инструмент» (16 P2.3).
  Удержание клика стика как модификатор запрещено: усилие ~4–6 Н тем же пальцем,
  что и отклонение → 10–15 % ошибок на верхних/нижних секторах (вывод эргономиста).
- Появляется **по взгляду**: центр на луче взгляда, 0.60 м, повёрнут к голове
  в момент спавна, дальше **world-locked** (не привязан ни к голове, ни к руке).
  Ушёл >1 м или отвернулся >60° — меню закрывается (намерение брошено).
- **Выбор — два пути, «кто двинулся последним, тот и ведёт»:**
  - *Стик (путь Rust):* отклонение >0.55 полного хода входит в сектор; подсветка
    следует за углом стика мгновенно (без сглаживания).
  - *Луч (путь новичка):* правый луч по сектору + триггер.
- **Подтверждение флик-жестом:** стик вернулся из >0.55 в <0.45 → выбран сектор,
  который был подсвечен при отпускании. Полный жест: клик L3 → флик → готово (~250 мс).
- **Browse-режим:** если стик простоял в секторе >400 мс и вернулся в центр —
  НЕ подтверждать, меню остаётся открытым (медленный возврат = разглядывание,
  быстрый флик = намерение).
- **Отмена:** B, повторный L3, или подтверждение центра. Автозакрытия по таймауту нет.
- После закрытия — **дебаунс ввода 150 мс** (клики не «протекают» в сцену).

### Геометрия и раскладка

- Кольцо: внутренний радиус **0.035 м**, внешний **0.11 м** на 0.6 м (внешний край
  ≈10.4° — в комфортном конусе движения глаз, голова не нужна).
- **12 фиксированных слотов по 30°, позиции постоянны навсегда** (пространственная
  память — главная ценность радиала). По часовой с 12:00:
  **12 Select · 1 Measure · 2 Wall · 3 Floor · 4 Openings\* · 5 Furniture\* ·
  6 Blueprint · 7 Import · 8 Electric · 9 Heating\* · 10 Plumbing\* · 11 Paint**
  (\* — резерв: точка 0.006 м на 20 % альфы, пока инструмента нет).
  Частые Select/Wall — на кардинальных направлениях (быстрее и точнее по стику).
- Гистерезис границы сектора: **+4°** за геометрическую грань (12 секторов без
  дребезга).
- **Лестницы:** слоты радиала заполнены (12/12), а лестницы — связка этажей, то есть
  родня плитам: будущий инструмент лестниц входит **табом инструмента Floor**
  (Slab / Hole / Stairs), не новым слотом. Иконка `stairs` уже в наборе.
- Иконки на срединном радиусе 0.08 м, глиф 0.024 м (≈2.3°).
- Тинт сектора — **hue слоя инструмента** на 60 % насыщенности (инструменты и есть
  слои — правилу «hue = данные» не противоречит); подсветка — яркостью + rim #7FD9FF.
- **Центр-диск:** иконка+имя текущего инструмента (покой) / имя подсвеченного
  (сектор горячий). Имя живёт в центре, по-растовски — секторам хватает иконок.
  Подтверждение центра = отмена (остаться на текущем).

### Тайминги и хаптика (левый контроллер)

| Событие | Значение |
|---|---|
| Открытие | 120 мс, scale 0.90→1.00 + fade, ease-out |
| Закрытие/подтверждение | 80 мс fade; выбранный сектор — вспышка 80 мс |
| Подсветка сектора | мгновенно (следующий кадр) |
| Пересечение границы сектора | 0.25 / 8 мс |
| Пульс открытия | 0.3 / 12 мс |
| Подтверждение | 0.6 / 20 мс |
| Отмена | тишина (молчание = ничего не произошло) |

### Судьба палитры на левой руке

Ряд кнопок инструментов **удаляется**. Палитра остаётся **полоской Snap & Layers**:

- 5 снап-тумблеров (Cor/Edg/Grd/Ang/Scan) — теперь иконки-тумблеры;
- пассивный **чип текущего инструмента** (иконка + имя, слева цветовая кромка слоя
  4 мм, некликабельный) — левое запястье отвечает «что у меня в руке» одним взглядом;
- резерв под layer-чипы (свотч + eye + solo) из 16;
- palm-gating, lazy-follow, poke — без изменений. Размер 0.385 × **0.10**
  (0.14 с layer-чипами).
- Особое мнение pro-CAD (оставить ряд на релиз как fallback) отклонено 2:1;
  митигейшн: первые сессии полоска показывает хинт «Tools: click left stick»,
  пока радиал не использован 10 раз.

## 2. Словарь виджетов (12 типов рядов, жёсткий потолок)

Правила выбора: каждый интерактив ≥2° угловой цели; у каждой непрерывной
манипуляции есть дискретный путь (степпер/скраб/numpad) — тремор луча на 0.65 м
≈ ±4 мм по панели, проектировать выше этого пола.

| # | Тип | Вид | Когда |
|---|---|---|---|
| 1 | **Stepper** | caption [−] value [+] | дискретные шаги, ≤ ~20 значений или без границ (Level, Posts, Angle step). Спец не меняется: repeat 0.4 с → 8 Гц → ×5, детенты, двойной тик на границе. Зона значения кликабельна → numpad |
| 2 | **Slider** | caption + трек + ручка + значение справа | ограниченный непрерывный диапазон (Height 200–400, Reserve %, прозрачность плана) |
| 3 | **Segmented** | caption + 2–4 равные кнопки, все видны, активная инвертирована | ≤4 взаимоисключающих опций (Offset, Route, Cable, Join). **Убивает большинство Cycle** |
| 4 | **Select** | caption + значение + шеврон → **popup-список** | 5+ опций или динамические списки (Plan file, IFC file, Storey) |
| 5 | **Toggle** | caption + пилюля 0.030×0.016, ползунок 60 мс, ON = светлый + LED | булевы состояния панели (Ceiling off, снапы). Чекбоксы — ТОЛЬКО внутри multi-select списков, не как ряд |
| 6 | **Numeric field** | caption + значение в рамке + единица → **numpad-popup** | точный ввод. Один механизм на всё приложение; все значения Stepper/Slider тоже ведут сюда |
| 7 | **Color swatch** | caption + чип 0.024 → popup-сетка свотчей | Paint. Выбранный чип — rim #7FD9FF (состояние — римом, hue чипа = данные) |
| 8 | **Action button** | на всю ширину или 2×полширины, иконка слева | Load, Calibrate, Finish. **Деструктив:** outline + глиф, hold 0.5 с заливается #FF6B6B и срабатывает |
| 9 | **Readout** | caption + значение, без хрома и коллайдера, полная яркость | статусы, описания, метраж кабеля (тусклый = disabled, читаемое ≠ тусклое) |
| 10 | **Progress** | caption + бар (fill = hue слоя) + % | парсинг IFC. Indeterminate = 3 пульсирующие точки |
| 11 | **Header/divider** | капс 0.8°, 55 % альфы + линия #FFFFFF14 | обязателен в панели >6 рядов |
| 12 | **Tabs** | сегмент-полоса под заголовком, активный инвертирован + подчёрк слоя 4 мм | суб-режимы инструмента (Electric: Outlet/Switch/Wire/Panel). **Заменяет хак с подменой схем** — та же машинерия, но с видимым stateful-контролом |

**Слайдер — механика:** трек на всю ширину колонки контролов, визуально 0.006 м,
коллайдер 0.024 м; ручка 0.024×0.024. Триггер по ручке = относительный драг
(1:1 в координатах панели, не по углу луча — иначе gain меняется с дистанцией);
триггер по треку = absolute jump + драг. **Грип во время драга = точный режим ×0.1**
(грип-модификатор, как везде). Детенты схемы: хаптика 0.3/8 мс + примагничивание
±1.5 мм за 30 мс. Stick-scrub на ряде работает. Релиз = одна undo-команда.

**Select — механика:** popup-оверлей (не разворот на месте — reflow под курсором
запрещён), +0.01 м к зрителю, ≤7 видимых опций (ряд 0.030 м), дальше stick-scroll,
текущая — с галкой; коммит тапом; B/клик-мимо = отмена.

**Numpad:** 3×4, клавиши 0.032 м (2.8°), ряды 7-8-9 / 4-5-6 / 1-2-3 / ±·0·⌫,
футер [Cancel][OK], единица в шапке, текущее значение пре-выделено (первая цифра
заменяет). OK = одна undo-команда.

**Судьба существующего:** Stepper выживает без изменений; **Cycle уходит**
(Segmented ≤4 опций, Select для списков, Action для Load/Calibrate, Tabs для
режимов); подмена схем как паттерн суб-режимов уходит (формализована Tabs'ами).

## 3. Сетка и лейаут (канонические 0.65 м; 1° ≈ 0.0113 м)

- **Базовая сетка 6 мм** — каждый размер кратен 0.006 м.
- **Ширина панели 0.288 м** (≈25°).
- Ряд **0.030 м** (2.6°), шаг **0.036 м**, паддинги **0.012 м**, тайтл-бар
  **0.036 м** (grip-drag, как было). Авто-высота: `0.012·2 + 0.036 + tabs? + rows×0.036`.
- **Колонки: caption 42 % / control 58 %**, подписи выровнены влево по общей оси,
  контролы — вправо по общему краю (сканируемость панели параметров).
- **Минимум коллайдера 2.0°** (0.023 м) по меньшей стороне; +15 % гистерезис
  ховера; зазор коллайдеров ≥0.006 м.
- Типографика без изменений (Title 1.2° / Row 0.95° / Hint 0.8°) + **tabular
  figures** для чисел (не дёргаются при скрабе).
- **Потолок 8 рядов** под таб-полосой. Лечится прежде всего структурой (Tabs,
  Header), не скроллом; скролл — только динамическим спискам: стик ↑/↓ над панелью,
  3 ряда/с со снапом, edge-fade 0.036 м, тонкий индикатор-рейл справа
  (0.004 м, НЕ перетаскиваемый). Фиксированные схемы не скроллятся никогда.
- **Popup-правила:** +0.010 м к зрителю, скрим 40 % чёрного над родителем,
  коллайдеры родителя off, максимум один модальный слой, закрытие B/мимо/коммит,
  открытие 100 мс (0.95→1), закрытие 80 мс.

## 4. Состояния и обратная связь

Одна машина состояний на все виджеты:
`disabled → idle → hover → pressed → (dragging) → idle` + ортогональный флаг
`active` (radio/toggle/tab).

| Состояние | Визуал | Тайминг |
|---|---|---|
| idle | fill #292E3D, контент #E8ECF4 | — |
| hover | fill #3A4256, rim #7FD9FF (1.5 мм), scale 1.06 | 60 мс in / 90 мс out |
| pressed | scale 0.97 + вспышка 80 мс | мгновенно |
| dragging | rim остаётся, ручка scale 1.12, остальной ряд 70 % | пока захвачен |
| active | инверсия (светлый fill, тёмный контент) или акцент #55E6A0 | 60 мс |
| disabled | контент 25 % альфы, без коллайдер-реакции и хаптики | — |

**Карта хаптики (единственная авторитетная):** hover-enter 0.2/10 · клик 0.6/20 ·
детент 0.3/8 · граница диапазона — двойной тик 0.3/8 ×2 через 40 мс · захват драга
0.4/15 · коммит драга 0.5/25 · сектор радиала 0.25/8 · подтверждение радиала
0.6/20 · деструктив-заливка 0.7/30. Правая рука — события луча, левая — радиал и
палитра. Отмена, hover-exit, disabled — тишина.

**Бюджет анимаций:** ничего дольше 150 мс, кроме деструктивной заливки (500 мс
намеренно). Ease-out cubic везде; overshoot/bounce запрещены (инструмент, не игрушка).

Звука нет и в v1 не появится; резерв v2 — ровно три события (confirm, error,
destructive) поверх карты хаптики. Per-hover звук запрещён навсегда.

## 5. Иконки — принцип

- Дизайн-сетка **24×24**, SVG-пути строками в C# (`IconLibrary`), команды только
  M/L/H/V/C/Q/Z (без дуг A), **заливки** с evenodd-дырами, замкнутые подпути,
  ≤ ~40 команд на иконку.
- Тесселяция в меш на старте (`SvgTessellator`: флаттен Безье → кольца →
  `Polygon.TriangulateWithHoles`); один цвет на иконку, тинт — MPB в рантайме.
  Ни текстур, ни бинарных ассетов.
- Рендер ≥ **1.2°** (0.014 м на 0.65 м; 0.024 м в радиале/палитре).
- У каждой icon-only кнопки — tooltip (hint 0.8°, задержка 350 мс). **Трёхбуквенные
  аббревиатуры умирают везде**, кроме строки тултипа.
- Полный набор путей, токены цвета и до-пиксельные спецификации виджетов —
  раздел 6 (панель дизайнеров).

## 6. Визуальные токены и набор иконок (панель дизайнеров)

### 6.1 Иконки — стиль и контракт тесселяции

- **Заливные силуэты** (эстетика Material Symbols Filled), НЕ штрихи: штрих требует
  stroke-expansion-движка, а заливка — ровно то, что ест ear clipping; на 12–18 мм
  поверх тусклого passthrough силуэт держит контраст лучше 2-px линий. Все пути
  нарисованы с нуля для проекта (лицензий не тянем).
- Сетка **24×24**, live-area 20×20 (поля 2); толщина «штрихов-заливок» 2–3 юнита,
  минимум 1.5; дыра-прорезь ≥1.5 юнита (уже — заплывает на 12 мм).
- Грамматика: **абсолютные M L H V C Q Z**, без дуг (окружности — 4 кубика,
  k = 0.5523·r), evenodd, ≤ ~40 команд.
- **Контракт тесселятора:** дыры строго внутри контура (зазор ≥1 юнит); отдельные
  острова могут делить ребро, но НЕ частично перекрываться (evenodd превратил бы
  пересечение в дыру, а наш клиппер не делает частичных булевых).
- Один цвет на иконку, тинт — MPB `_Color`; углы острые (микрофаски не окупаются).
- Меши строятся на старте из строк в `Core/IconPaths.cs` — **код и есть источник
  истины** по путям; здесь только реестр имён.

**Набор (45):** инструменты — select-cursor, tape-measure, wall (кирпичи вперевязку),
floor-slab (изометрия), blueprint (лист с пазом-планом), import-file, electric-plug,
paint-roller + резерв door-window, furniture, radiator, pipe; объекты сцены — stairs
(профиль марша). **Суб-режимы Electric** (иконки таб-полосы): outlet (розетка с двумя
гнёздами), switch (клавиша с прорезью), wire (орто-колено — как реально ведём трассы),
breaker-panel (щиток с автоматами). Глифы — plus, minus, chevron-left/right/down,
check, cross, eye (зрачок-дыра), eye-off (закрытое веко с ресницами — не «глаз +
слэш»: слэш частично перекрывал бы контур), lock, trash, copy, undo, redo, gear,
folder (пикеры файлов), calibrate (перекрестье — калибровка плана), storey (стопка
этажей — фильтр Import), eraser (Original look в Paint), палитра снапов (единый язык:
точка привязки = ромб/квадрат, геометрия = полосы): grid-snap, corner-snap, edge-snap,
angle-snap, scan, palette, dropper, hand-grab, numpad. Бюджет: худшая (palette) —
166 треугольников, тест <200.

### 6.3 Размеры, радиусы, z-эшелоны

Мастер-сетка лейаута — §3 (панель 0.288 м, ряд 0.030, шаг 0.036); спецификации
дизайнеров в референсе 400 мм пересчитываются пропорционально (×0.72).

- Радиусы скругления: **S 3 мм** (чипы, свотчи, чекбоксы) · **M 6 мм** (кнопки,
  поля — стандартная плашка, скруглённый прямоугольник процедурно: 4 веера по
  4 сегмента, ~34 верта, заменяет плоские квады) · **L 10 мм** (панели, поповеры)
  · **full** (тумблеры, хаб радиала).
- Римы: hairline 1 мм (делители, покой) · focus 2 мм (Hover/FocusRing) ·
  active 3 мм (Selected-полоса/подчёрк).
- **Z-эшелоны с шагом 6 мм** (к зрителю = минус): panel-bg +0.006 · plate 0 ·
  content −0.006 · popover-plate −0.012 · popover-content −0.018 ·
  modal-plate −0.024 · modal-content −0.030. Промежуточных z не изобретать
  (z-fight поверх passthrough мерцает).
- **Политика альфы (Adreno, overdraw):** прозрачность разрешена только
  disabled-контенту (α 0.40), скриму радиала (vertex-alpha) и fade ≤150 мс.
  Всё остальное — заранее смешанные сплошные токены.

### 6.4 Ключевые визуальные решения виджетов

- **Slider:** трек InsetBg r3, заполнение TrackFill → TrackFillActive при захвате,
  ручка 16 full-radius белая (18 при захвате), детенты — риски 1×4 Divider.
- **Select:** закрыт — плашка ButtonBg, значение LabelDim, шеврон; раскрыт —
  поповер PanelBg+rim, выбранный ряд = галка + текст Selected.
- **Toggle:** off = InsetBg + rim, ручка слева; on = ToggleOnBg, ручка справа,
  всегда белая; слайд 80 мс.
- **Segmented:** контейнер InsetBg; активный сегмент ButtonBg + Selected-подчёрк
  3 мм снизу; неактивные подписи LabelDim.
- **Destructive:** покой — иконка+текст Danger на ButtonBg; hover — DangerTint +
  rim Danger; взведён — заливка Danger, контент LabelDark, авторазрядка 3 с.
  Рядом с primary-commit не ставить.
- **Numeric invalid:** rim Danger 2 мм + значение Danger.
- Иконка всегда **слева** от подписи, зазор 8 мм; тяжёлые снизу иконки (trash,
  lock) оптически поднимать на 0.5 юнита.

### 6.5 Радиал — визуал (пропорции дизайнеров на геометрии §1)

Внешний R = 0.11 м: кольцо 0.45R…1.00R, хаб-диск 0.36R (PanelBg + hairline);
зазор секторов 2.5° (читается волосяной линией поверх passthrough); иконка 18 мм
на биссектрисе 0.72R, **всегда вертикальна** (не вращается с сектором); подпись —
только в хабе (одна TMP-строка). Активный инструмент — дуга-штрих 3 мм Selected
по внешнему ободу сектора + иконка Selected. Hover — ButtonHoverBg + rim Hover по
внешней кромке, сектор растёт радиально ×1.06 наружу (60 мс). Резервные слоты —
ButtonDisabledBg, иконка-точка на α 0.40. **Скрим:** один диск 1.25R за кольцом,
vertex-alpha градиент PanelBg α 0.55 в центре → 0 на краю — единственная большая
прозрачная поверхность в приложении.

### 6.6 Правила для авторов инструментов (дополняют §7)

1. Один глагол/существительное = одна иконка; то же действие в двух инструментах —
   та же иконка. Новая иконка — только для нового понятия.
2. Все цвета — из токенов через MPB; `new Material` в рантайме — блокер ревью.
3. Каждый интерактив ≥ 24×24 мм хит-зоны, даже если визуал меньше (чекбокс, свотч).
4. Новые плавающие UI — только на эшелонах popover/modal.
5. Текст — только через 5 ролей TMP; цифры в ридаутах — tabular (`<mspace>`).
6. Деструктив — всегда двухшаговый и физически отделён от primary; удаления —
   командами (undo), по правилам 12.
7. Иконки-меши строятся в Setup и кешируются; per-frame геометрии нет.
8. Каждый новый путь — EditMode-тест: парсится, замкнут, дыры внутри, <200 треугольников.
9. Изменил токен — обнови этот док в том же коммите (`UiTokens` — истина, док — зеркало).

## 7. Анти-паттерны (обязательный список запретов)

1. Никакого head-locked UI после открытия — gaze-спавн, затем world-lock.
2. Никакого dwell-to-select.
3. Никаких вложенных радиалов/подменю — один уровень; нужен второй → это инспектор.
4. Никаких удержаний клика стика как модификатора (A-hold — можно, face-кнопка).
5. Никаких целей луча <2°, перетаскиваемых скролл-ползунков, resize-грипов.
6. Никакого reflow под курсором: опции не разворачиваются на месте, ряды не
   съезжают при открытом popup, инструменты не меняют сектора.
7. Никаких «слепых» циклов: все опции видны (Segmented) или списком (Select).
8. Максимум один модальный слой; каждый popup закрывается по B и клику-мимо;
   150 мс дебаунс после закрытия.
9. Hue не кодирует состояние, системные цвета не слои; **#FF6B6B — третий
   системный** (деструктив), слоем быть не может.
10. Никаких панелей выше плеч или ниже −30° взгляда; спавн на взгляде −10°;
    правило персистентной парковки инспектора остаётся (>45°/>2.5 м).
11. Ни одной иконки без тултипа; тултип не может быть единственной подписью
    деструктива.
12. Никакого автозакрытия по таймауту — закрывает пользователь, не время.

## 8. Архитектура (скелет)

```csharp
// RoomPlanner.Core — чистое, тестируемое
static class RadialMath      // угол→сектор (12, гистерезис +4°), пороги 0.55/0.45,
                             // флик-vs-browse (<400 мс), позиции секторов/иконок
static class SvgPath         // парсер M/L/H/V/C/Q/Z (abs/rel) → подпути (полилинии)
static class SvgTessellator  // подпути → внешние кольца + дыры (evenodd) →
                             // Polygon.TriangulateWithHoles → verts/tris (XY)
static class IconLibrary     // словарь id → path data (24×24)
static class UiTokens        // расширение UiColors: полный набор токенов (раздел 6)
// SettingsSchema v2: SettingKind { Stepper, Slider, Segmented, Select, Toggle,
//   Numeric, Swatch, Action, Readout, Progress, Header }  + TabbedSchema
static class PanelLayout     // сетка 6 мм: позиции рядов/колонок, авто-высота

// RoomPlanner.App (Tools/)
class RadialMenu             // рендер кольца (процедурные арк-меши), 2 инстанса:
                             // инструменты (L3) и контекст (A-hold, v2)
class IconRenderer           // MonoBehaviour: id → меш в Awake, MPB-тинт
class InspectorPanel         // v2: генерация 12 типов рядов, popups, скролл
class UiPopups               // Select-список, Numpad, Swatch-сетка (модальный слой)
class ToolMenu               // v2: полоска Snap & Layers + чип инструмента

// Editor/Setup
SetupRadial, SetupPalette v2, SetupInspector v2
```

Ввод: `MeasureInput` получает `StickClickPressed(left/right)`; `ToolManager` — драг
слайдера (захват), модальный слой, дебаунс радиала. `ITool` расширяется
`IconId` (ключ в `IconLibrary`) и `AccentColor` (hue слоя).

## 10. Аудит покрытия (2026-08-10) и карта миграции U7

Что каждый инструмент получает при миграции со старых Stepper/Cycle:

| Инструмент | Новые виджеты | Иконки |
|---|---|---|
| Select | группа выбора (Readout) + per-instance ряды поставщиков — без изменений механики | select-cursor; заголовок типа объекта: wall/floor-slab/stairs/outlet/switch/wire/breaker-panel/tape-measure |
| Measure | настроек нет (кандидат v2: единицы cm/m) | tape-measure |
| Walls | Thickness/Height/Angle — Slider+Numeric; Offset/Join/Place — **Segmented** | wall |
| Floor | Level — Stepper+Numeric; Thickness — Slider; будущее: табы Slab/Hole/**Stairs** | floor-slab, stairs |
| Blueprint | Scale — Slider; Rotation — Stepper; Calibrate — **Action(calibrate)**; Plan file — **Select(folder)**; Load — Action | blueprint, calibrate, folder |
| Import | IFC file — **Select(folder)**; Load — Action; Storey — **Select(storey)**; парсинг — **Progress** | import-file, folder, storey |
| Electric | Mode — **Tabs с иконками** (outlet/switch/wire/breaker-panel); Cable/Route — Segmented; Height — Slider; Reserve — Slider; BOM — Readout | electric-plug + 4 суб-иконки |
| Paint | Color — **Swatch**; Original look — **Action(eraser)**; AO/SSAO — Toggle (см. гэп ниже) | paint-roller, palette, eraser |

- **Глобальная панель настроек (gear)** — сейчас негде жить общим параметрам:

  вообще не в UI. Место — «gear»-Action на полоске палитры → обычная панель схемы.
- Единицы измерений (cm/m/inch) для Measure.
- Радиал-слот лестниц не нужен — таб Floor (см. §1).
