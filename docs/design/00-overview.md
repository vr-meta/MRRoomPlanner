# 00 — Стек и сквозной принцип

## Стек

- **Клиент на Quest** — Unity 6 (6000.0.81f1) + C#. Движок рисует MR, собирает `.apk`,
  исполняет наш код (`MonoBehaviour`). Meta XR Core SDK + **MRUK** дают понимание
  комнаты, Depth API — окклюзии, Passthrough — фон реального мира.
- **База** — официальный сэмпл Meta **Virtual Home** (room reskinning на EffectMesh).
- **Бэкенд / общий формат / нативные модули** — можно на **Rust** (прокси к Claude,
  библиотека формата проекта, тяжёлые вычисления через P/Invoke, парсинг IFC). В шлеме —
  только C#.
- **AI** — Claude API (`claude-opus-4-8`) через structured output; вызывается по сети,
  не покадрово.

## Сквозной принцип (важнейший)

> Всё геометрическое и отделочное храним как **параметрические данные**, а меши и
> материалы **генерируем процедурно** из них. Никаких булевых операций (CSG) над
> готовыми мешами и никаких «запечённых» развёрток.

Почему: параметры остаются редактируемыми, поддерживают Undo/Redo, точный числовой
ввод и сохранение в кросс-платформенный формат. CSG-объединения и авто-развёртки —
хрупкие, медленные и необратимые.
