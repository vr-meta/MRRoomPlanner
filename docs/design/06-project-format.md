# 06 — Формат проекта и переносимость (Project I/O) 🧭

Два слоя данных:
- **Семантика** (источник истины) — наш **JSON**: комнаты (стены/пол/потолок из
  MRUK-JSON), граф стен, проёмы, отделка (материалы/зоны/UV-привязки), мебель, инженерные
  сети, подложка чертежа + калибровка, метаданные.
- **Меш** — **glTF/glb** для DCC (3ds Max) и рендеров.

Возможности:
- **Снял на объекте → доделал дома** через JSON-сериализацию сцены (MRUK
  `SaveSceneToJson`/`LoadSceneFromJson`); дома редактируем модель, физической привязки к
  месту нет — это ожидаемо.
- **Мульти-рум скан** (по комнатам, `MRUKRoom[]`); сшивка в план этажа — наша логика.
- Кросс-платформенный контейнер `.json` + папка ассетов; облако Meta не обязательно.
- Колокация (несколько человек в одной комнате) — Shared Spatial Anchors / Space Sharing
  (по желанию).

Обмен с CAD/BIM (IFC, DWG, glTF/FBX) — вынесен в [08-interop](08-interop.md).
