# 02 — Стены (Wall Builder) ✅ (Фаза B реализована)

> **Состояние:** модель графа, стыки и правка реализованы в Фазе B
> (план и отчёт по шагам — [13-phase-b-wallgraph](13-phase-b-wallgraph.md)).
> Реализовано: `WallGraph` (узлы/сегменты, сплит = T-стык, стабильные id), `WallMesh`
> (стык из графа: тупик/угол/T, miter limit), один view = один сегмент, параметры за
> экземпляр, **ручки вершин**, единый `SnapFinder`. Задел: `WallSegment.Openings` (Фаза D),
> `WallGraph.FindClosedLoops()` (комнаты, Фаза E).
> Отложено: высота за верхнюю грань ручкой (сейчас — шаг в инспекторе), Round/Bevel в T-узлах
> (степень 3+ всегда режется прямым срезом).

## Модель: параметрический граф «узлы + сегменты»

```
WallNode     = точка на полу (стык/конец стены), знает свои сегменты
WallSegment  = стена между двумя узлами; свойства: thickness, height, baseHeight(=0)
WallGraph    = список узлов и сегментов + операции
```

- Стена — **сегмент между двумя узлами**, а не «коробка». Меш строится процедурно.
- **Соединения получаются сами**: стыкующиеся стены делят общий узел. Union не нужен.
- Двигаешь узел — все примыкающие стены пересчитываются.

## Стыки и T-образные соединения

- Ведём третью стену к существующей → **snap на стену** → в неё вставляется **новый
  узел** (сегмент разбивается на два) → к нему крепится третья стена. В узле сходятся
  3 сегмента = T-стык.
- «Кликнул на боковую грань/конец и повёл дальше» = старт новой стены в существующем
  узле → стены соединены и продолжаются под нужным углом.

## Генерация меша стыков (без CSG)

- ~~v1: коробки внахлёст~~ — пропущено: сразу сделан контурный стык.
- **v2 ✅:** грани соседей пересекаются в узле (`WallMesh`) — чистые углы и тройники без CSG.

## Высота

- `height` — параметр сегмента. Тянем за **верхнюю грань** ручкой-манипулятором →
  меняется высота, рядом число в см **от пола** (низ = пол из Scene API). Можно ввести
  точное значение. Шаг привязки (напр. 5 см) + магнит к высоте потолка из скана.

## Привязки

Узлы, грани, сетка (напр. 10 см), углы (0/45/90°), числовой ввод длины/толщины/высоты.

## Скелет классов

```csharp
class WallNode    { Vector3 position; List<WallSegment> segments; }
class WallSegment { WallNode a, b; float thickness = 0.1f; float height = 2.7f; float baseHeight = 0f;
                    List<Opening> openings; }
class WallGraph   { List<WallNode> nodes; List<WallSegment> segments;
                    WallNode SnapOrCreateNode(Vector3 p);
                    void SplitSegmentAt(WallSegment s, Vector3 p);   // T-стык
                    Mesh Build(); }
```

Проёмы в стене — см. [03-openings](03-openings.md).
