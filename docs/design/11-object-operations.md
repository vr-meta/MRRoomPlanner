# 11. Манипуляции по типам объектов (роадмап редактирования)

Единый каталог: **что можно делать с каждым типом объекта**, что у него в инспекторе,
какие привязки, что нужно в модели данных, и в каком порядке внедрять. Составлен по итогам
ревью двух экспертов (VR-interaction/UX + домен архитектурных VR-CAD), приземлён на текущий код.

Сквозной принцип (`00-overview`, `CLAUDE.md`): **параметры → процедурный меш**, без CSG.
Стыки — из общих узлов графа (`02-walls.md`), проёмы — параметр сегмента, не булев вырез
(`03-openings.md`), отделка — метрические UV + прямоугольные зоны (`04-surfaces-materials.md`).

Связанные документы: [10-controls](10-controls.md), [02-walls](02-walls.md),
[03-openings](03-openings.md), [04-surfaces-materials](04-surfaces-materials.md),
[09-project-structure](09-project-structure.md). Память: `ui-foundation-palette-inspector`.

## 0. Главный вывод и текущий разрыв

Сейчас всё — **только создание, без выбора**: нельзя выделить поставленный объект и
изменить его. Инспектор показывает настройки *активного инструмента*, а не *выбранного
объекта*. Стены/полы хранят точки и перестраиваются `Build(...)`, но ручек/гизмо нет.

**Ключевое решение (оба эксперта):** ввести режим **Select/Edit** — отдельный инструмент,
который владеет наведением, выбором, гизмо и **перепривязкой инспектора к выбранному
экземпляру**. Инструменты создания остаются «только создание». Это и есть недостающий слой.

**Несущая зависимость:** для стыков/проёмов/комнат нужен **WallGraph** (узлы+сегменты) —
на нём завязано почти всё ниже.

## 1. Фундамент (строим один раз, до правки по типам)

1. **Идентичность объектов + реестр.** Общий `PlanObject`/`ISelectable` (стабильный `id`,
   `Type`, `Bounds`, `Transform` для подсветки/ручек). Центральный `SceneModel` вместо
   разрозненных списков `_walls`/`_floors`/measurements — общая база для операций, undo,
   save/load.
2. **Инструмент Select** — луч → пик → подсветка → инспектор показывает **выбранный
   объект** (а не инструмент). По умолчанию активен именно Select (дом-режим), инструменты
   создания — опционально.
3. **Undo/Redo (стек команд)** в `Core` (тестируемо). Каждая операция — команда
   (before/after параметров, rebuild). Кнопки **X = Undo, Y = Redo**. Перетаскивание пишет
   **одну** команду на релиз. Заодно делает отменяемым и само создание.
4. **`EditHandle`** — обобщение `MeasurePointHandle` (Owner + Index + Type + коллайдер).
   Переиспользуется для вершин стен, углов пола, узлов проёмов/MEP.
5. **`SnapService`** — единый сервис привязок (сейчас логика размазана по `WallController`/
   `FloorController`/`MeasureController`): to-node (corner), to-edge, to-face, to-grid,
   to-angle, to-level, along-host, to-sibling. Тумблеры уже есть (Corner/Edge/Grid/Angle) —
   добавить Face/Level/Along-host.
6. **Инспектор → по объекту.** `InspectorPanel.BindInstance(sel)`: показывает группу под тип
   объекта и поля **этого экземпляра**; правка поля пишет в объект + `Build` + команда undo.
   При снятии выбора — возврат к настройкам активного инструмента. Заголовок: «Wall #3» vs
   «Wall — defaults». Это и есть Фаза 1.5 (`SettingsSchema`/`SettingField`) из чек-листа.

## 2. Грамматика ввода (общие глаголы → жесты Quest)

Указатель — **правый** контроллер (луч), палитра — левая рука. Согласовано с `MeasureInput`,
чтобы не ломать привычки.

| Глагол | Жест / кнопка | Ближний poke / дальний луч | Заметки |
|---|---|---|---|
| Hover | луч на объект → pulse, подсветка | луч (poke — P2) | как в Measure `UpdateHover` |
| Select | **Trigger** по объекту (в Select) | луч | по пустоте — снять выбор |
| Multi-select | **Grip + Trigger** добавить к выбору | луч | grip разрешается по контексту (см. ниже) |
| Move | удержание **Trigger** на теле/ручке, тащить | луч (ray-carry на `_grabDist`) | как `InspectorPanel.MovePanel` |
| Move по оси | **Grip** во время move | — | `SnapToAxis` |
| Rotate | ручка-кольцо, свайп | луч | шаг угла grip (`SnapToAngleXZ`, `AngleStep`) |
| Scale/Resize | ручка-угол, тащить | луч | grip = равномерно (P2) |
| Duplicate | **A (Button.One)** у выбранного | — | A свободна |
| Delete | **B (Button.Two)** у выбранного | — | отменяемо |
| Undo / Redo | **X / Y** (левая рука) | — | стек команд |
| Точная правка | инспектор −/+; фокус поля + **стик ←/→** скраб | луч | коммит = одна команда |
| Nudge | выбран + **стик** | — | шаг `GridSize` |

**Конфликт grip** (снап-модификатор / таскание инспектора / multi-select) решается по
приоритету контекста, как уже ветвится `ToolManager.Update`: (1) над заголовком инспектора →
таскать панель; (2) активен инструмент создания → снап-модификатор; (3) Select + над
объектом → add-to-selection (клик) / ось-угол (во время drag); (4) по пустоте — idle.
Новых кнопок не нужно.

## 3. Манипуляции по типам (P1 первым, P3 — на будущее)

### 3.1 Measurement (в основном готово)
Готово: точка/цепочка/тянуть точку/удалить(hover+B)/магнит/воздух/бейдж-см/схлопывание.
Добавить: выбор всей линии; **точная длина** (число); перемещение всей линии (P2);
угол/уровень (future); привязки к узлам стен/проёмам/углам пола (через `SnapService`);
сделать первоклассным `PlanObject` (сохранение/undo/выбор).

### 3.2 Wall — весь объект (P1, если не указано)
Выбрать · переместить весь (XZ, grip=ось) · **толщина/высота/offset за экземпляр** (сейчас
только глобально при создании) · сменить join (P2, join — свойство **узла**) · дублировать
(A, P2) · удалить (B, отменяемо) · split/insert вершины (P2) · закрыть контур→Room (P3) ·
flip «внутренней» стороны (сейчас определяется один раз по камере — сделать свойством).

**Инспектор Wall:** Thickness (20 см, 2–100, шаг 2), Height (270, 20–500, шаг 10),
Base height (0), Offset (Outer/Center/Inner), Join (Miter/Bevel/Round, per-node),
Interior side (flip), Segment length (число), Face A/B material (→ §отделка).
Меню-значения = дефолты для следующей стены; выбранная стена правит свои копии.

### 3.3 Wall — вершины/сегменты/узлы (P1)
Показ ручек вершин (авто при выборе) · **тянуть вершину** (мутирует `Points[i]` + `Build` —
«стены как линии в AutoCAD») · снап оси/угла (grip) · магнит к узлам/рёбрам (`TrySnapToNode`,
включая T) · вставка/удаление вершины (P2) · перемещение сегмента-ребра (P3) · **общий узел
графа** (тянешь общий угол — двигаются обе стены; нужен `WallGraph`, P3).

### 3.4 Floor — плита (P1)
Выбрать конкретную плиту (сейчас только LIFO-удаление) · толщина/уровень за экземпляр
(**расцепить с `WallThickness`** — сейчас пол берёт толщину стены) · удалить любую · тянуть
углы (resize) · переместить (P2) · дубли (P3) · **полигональный контур + дыры** (лестницы,
P3) · авто-пол из замкнутого контура стен (P3) · зоны отделки (P3).
**Инспектор Floor:** Level, Thickness, Outline(углы), Plan scale (project-level),
Top/Bottom material.

### 3.5 Opening — дверь/окно (P3; после базовой правки — самый ценный шаг)
Разместить на стене (луч→грань) · двигать вдоль стены (1-DOF, едет со стеной) · ширина/
высота/подоконник · пресеты (дверь 900×2100, окно 1200×1400@900) · сторона/навес · re-host ·
вставка glTF-модели · привязка к реальному DOOR/WINDOW_FRAME из скана · удалить (стена
зашивает проём).
**Модель:** `Opening` — параметр `WallSegment.openings` (позиция вдоль сегмента), меш стены
**панелизуется** вокруг (простенки/перемычка/подоконник) — значит билдер стены должен стать
opening-aware ⇒ **проёмы зависят от WallGraph**. Валидация из `03-openings.md`.

### 3.6 Room/Space (P3, производный объект)
Детект как замкнутый контур сегментов → имя+площадь · переименовать · назначить отделку ·
авто-плита · split перегородкой · merge · transform на плане (сборка этажей) · schedule
(площади/периметры) · captureState. **Модель:** `Room` = boundary(loop) + метаданные,
производный от `WallGraph`; иерархия `Project→Storey→Room` (`09`).

### 3.7 Furniture (P3)
Разместить из каталога (glTF) · move/rotate(yaw)/scale/duplicate/delete · snap к полу/стене/
на другую мебель · align/array/mirror · group · swap-модель · AI-расстановка (`05`) · ingest
скан-объёмов (стол/диван) · слой видимости. **Модель:** `Fixture` = ссылка на каталог + Pose
(лёгкий, не процедурный).

### 3.7a Импортированные из IFC предметы (реализовано 2026-08-16, issue #135)
Запечённые элементы (мебель, сантехника, прокси, перила) до сих пор были «нарисованными»:
`Selectable` без коллайдера и без регистрации — их нельзя было ни выбрать, ни удалить, а
файл всегда привозит лишнее. Теперь у каждого — `MeshCollider` на слое выбора и запись в
`SceneModel`, и дальше работает общая машинерия: Select подсвечивает, **B удаляет**
(`DeleteCommand`, отменяемо), фильтр этажей и сохранение уже умеют пропускать скрытые —
удалённый диван не воскресает после перезагрузки проекта. Вид — свой,
`SelectableKind.Mep` (раньше падал в `Measurement`), его читают фильтр табов Paint
(вкладка `Objects` красит импорт) и рейкастер поверхностей. Плата — ~230 mesh-коллайдеров
на квартиру, печём один раз при импорте; счётчик в логе импорта.

### 3.8 MEP — электрика/отопление/сантехника (P3)
Точечные (розетка/выключатель/светильник/радиатор/кран/трап) на стене/полу с высотой ·
маршруты-полилинии (труба/кабель) node-to-node · правка вершин · ветвление/тройник · связь
фикстур↔маршрут · диаметр/уклон/стояки · **слои show/hide/solo** по дисциплине · clash-check
· легенда/schedule. **Модель:** `MepFixture`(host+height) + `MepRoute`(path+size) — маршрут
= полилиния→процедурная труба (как стена). Слои общие с мебелью (`07`).

### 3.9 Surfaces &amp; Materials (P3, сквозной «объект»-отделка)
Назначить материал грани/полу/потолку · tile size / UV origin / rotation · прямоугольная
зона (панель/фартук) как submesh · move/resize зоны · continuous-across-corner · (v2) покраска
маской, triplanar, двусторонние грани. **Модель:** `Surface`/`WallFace`/`SurfaceRegion`;
метрические UV генерятся при билде (у стен сейчас UV нет — добавить; у пола уже world-UV).

## 4. Целевая модель данных (вся no-CSG)

```
Project
 └ Storey(Floor) { index, floorToFloor, y, rooms[] }
    └ Room        { name, boundary(loop of WallSegment), slab(Floor), scan(MRUKRoom), pose, captureState }
       ├ WallGraph { WallNode[], WallSegment[] }                    // §3.2/3.3 — спина
       │   WallSegment { thickness,height,base,offset, faceA/B(Surface), openings[] }  // проёмы/отделка висят тут
       ├ Floor(slab) { level, thickness, outline[], holes[], zones[] }
       ├ Fixtures[]  { catalogId, pose, scale, layer }
       └ Routes/MEP[]{ discipline, path[], size, fixtures[] }
Layers { Interior, Electrical, Heating, Plumbing … visible }
SceneModel { все PlanObject по id } + CommandStack (undo/redo)
SnapService
```
**WallGraph — load-bearing:** проёмы, комнаты, hosted-MEP, отделка граней ссылаются на
сегменты/узлы.

## 5. Порядок внедрения (постепенно)

- **Фаза A — Фундамент выбора.** `PlanObject`/`SceneModel` + инструмент **Select** +
  инспектор-по-объекту + **Undo/Redo (X/Y)**. Уже даёт: выбрать/удалить/переместить любую
  стену/плиту/измерение. *Наименьшее изменение, превращающее рисовалку в редактор.*
- **Фаза B — WallGraph + правка стен.** Узлы/сегменты; `WallController` создаёт/сплитит общие
  узлы при снапе (T-стыки); текущий `Wall.cs` становится рендерером сегмента; толщина/высота/
  offset/join за экземпляр; **тянуть вершины**; заодно вынести `SnapService`.
- **Фаза C — Правка пола.** Расцепить толщину пола от стен; выбрать/двигать/удалять плиту;
  тянуть углы; число-размер; затем полигон+дыры.
- **Фаза D — Проёмы (двери/окна).** ⭐ *Рекомендация обоих экспертов — самый ценный шаг после
  базовой правки:* без дверей/окон нельзя планировать квартиру; дизайн готов (`03`), no-CSG
  панелизация; проверяет WallGraph end-to-end; открывает сборку по дверям и ingest скана.
- **Фаза E — Комнаты и сборка.** Детект замкнутого контура → Room (имя/площадь), авто-плита,
  сборка на плане (снап по общей стене/двери), стек этажей (`09`).
- **Фаза F — Отделка/материалы.** Метрические UV в билдере стен, двусторонние грани, зоны
  (`04`).
- **Фаза G — Мебель + каталог + AI (`05`); MEP + слои (`07`); Interop IFC/DWG/glTF (`08`).**

Front-load Фаз A–C: они переиспользуют ~80% существующего кода (ручки, снап, `Build`, группы
инспектора) и закрывают петлю «выбрать → править → undo», которую чек-лист откладывал.

## 7. Гизмо/ручки — под Quest 3
Константный **угловой** размер (~1.5–2°: ~4–5 см на 1.5 м, ~8–10 см на 3 м), пересчёт от
дистанции камеры. Вершина-шар: коллайдер ×1.4 визуала (щедрый хит), hover 100%+×1.12,
grab = акцент. Rotate-ring: тор в плоскости, тик каждые `AngleStep`. Цвета: серый idle /
cyan hover / amber drag / green snap / red delete. Ручки рисуются **поверх** (depth-bias),
иначе тонут в скане. Хаптик на hover/grab/каждый snap-tick/сильнее на delete. Общий базовый
`EditHandle` для всех типов.
