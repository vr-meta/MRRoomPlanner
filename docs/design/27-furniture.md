## 1. Ключевое решение: каталог = набор коллекций

Каталог не плоский. **Коллекция (пак)** — папка с манифестом `collection.json` и файлами
`.glb`. Пользователь сначала выбирает коллекцию, потом предмет внутри неё. Так паки
не смешиваются, их можно подключать и отключать, а источник (бандл / скачано / онлайн)
для инструмента неразличим — меняется только поле `Source`.

```
StreamingAssets/Furniture/
  kenney-furniture/        collection.json  sofa.glb  bed.glb  …
  quaternius-interior/     collection.json  …
persistentDataPath/FurnitureCache/
  polypizza-downloaded/    collection.json  <sha>.glb  …      ← v2, тот же формат
```

**Габариты — из манифеста, не из меша.** Модели CC0 стилизованы; планировщик, который
врёт про размеры, бесполезен. Загруженная модель равномерно масштабируется так, чтобы её
bbox совпал с объявленным реальным размером (`FitScale`).

### `collection.json`

```json
{
  "Id": "kenney-furniture", "Title": "Kenney Furniture Kit",
  "Author": "Kenney", "License": "CC0", "LicenseUrl": "https://kenney.nl/assets/furniture-kit",
  "Items": [
    { "Id": "sofa", "Name": "Sofa", "Category": "Seating", "Anchor": "Floor",
      "File": "sofa.glb", "Size": {"x":2.10,"y":0.80,"z":0.90}, "Fit": "Uniform",
      "YawOffset": 0, "Tris": 1240 }
  ]
}
```

- `Category` — закрытый enum: `Seating · Table · Storage · Bed · Kitchen · Bath · Appliance · Decor`
  (свободных строк нет — панель группирует по нему).
- `Anchor` — `Floor · Wall · Ceiling · Counter`: чем ограничен предмет.
- `Size` — реальные метры (X = ширина, Y = высота, Z = глубина), `YawOffset` — доворот,
  если модель смотрит не «лицом на +Z».
- `Fit` — как модель подгоняется под `Size`: `Uniform` (по умолчанию — равномерно, пропорции
  сохраняются: диваны, кресла, растения) или `Stretch` (по каждой оси — корпусная мебель и
  техника, где важна точная высота столешницы). Стилизованные CC0-паки не пропорциональны
  реальности: кухонная тумба Kenney — 0.43 × 0.45 × 0.45 при настоящих 0.60 × 0.85 × 0.60.
- Битые записи (нулевой размер, пустой файл, неизвестный якорь) **отбрасываются со
  счётчиком**, а не превращаются в мусорный объект (правила 12 §1.3).

### Что в бандле v1

Kenney Furniture Kit (140, CC0) + Quaternius Ultimate House Interior (80+, CC0) — оба
public domain, без атрибуции, единицы мегабайт. Отклонены осознанно: Amazon Berkeley
Objects (CC BY-NC), 3D-FUTURE (запрет коммерции), BIMobject/Polantis/3D Warehouse (нет
права на перераспространение), брендовые модели производителей, агрегаторы с непрозрачным
происхождением. CC-BY-паки допустимы, но требуют экрана Credits.

## 2. Размещение (Core, чистая математика)

`FurniturePlacement.Solve(hit, normal, size, anchor, yaw, options) → Pose`:

| Якорь | Правило |
|---|---|
| `Floor` | низ bbox ложится на поверхность (не утоплен, не висит); XZ = точка прицела |
| `Wall` | задняя плоскость предмета лежит на грани стены, yaw развёрнут по нормали, высота монтажа — дефолт категории (подвесной шкаф 1.40 м, раковина 0.85 м) |
| `Ceiling` | верх bbox на потолке (резерв — светильники) |
| `Counter` | на верхней грани другого предмета (резерв v2) |

- **Back-to-wall snap** для напольных: стена ближе `0.35 м` и примерно параллельна →
  предмет сдвигается назад до касания и доворачивается по стене. Тумблер `Snap to wall`.
- **Yaw** — степпер 15° в панели; грип во время прицеливания квантует угол (та же
  конвенция, что у стен, `AngleStep`).
- Ноль аллокаций в пер-кадровом пути: структуры, без LINQ (правила 12 §4.1).

Проверка вместимости — призрачный bbox: не влезает (пересекает стену/другой предмет) →
рамка красится в `Danger`, постановка запрещена.

## 3. Инструмент и панель (по дизайн-коду 20)

Слот радиала — **5** (`furniture`, зарезервирован; компас не пересортировывается).

**Табы: `Place` / `Move`** (суб-режимы — только Tabs, `Cycle` запрещён).

Страница `Place`:

| Ряд | Виджет | Содержание |
|---|---|---|
| Collection | `Select` | список подключённых коллекций (динамический → popup со stick-scroll) |
| Category | `Select` | категории внутри коллекции + `All` |
| Item | `Select` | предметы категории |
| Rotate | `Stepper` | шаг 15°, зона значения → numpad |
| Snap to wall | `Toggle` | back-to-wall snap |
| Size | `Readout` | `210 × 90 × 80 cm` выбранного предмета |
| Source | `Readout` | автор + лицензия (честность по CC-BY) |

Прицел: ретикл + призрачный bbox в решённой позе; **Trigger — постановка одной
undo-записью** (`CreateCommand`). `B` у поставленного предмета — удаление (командой).

Страница `Move`: прицелиться в любую мебель (каталожную **или импортированную из IFC**),
удержание триггера — везти по плоскости пола на её собственной высоте, снап к стене
работает, грип — yaw по 15°, отпускание — **одна** `MoveCommand` (+ команда поворота,
если yaw менялся). Живой драг — только transform-превью, без пересборки геометрии
(правила 12 §4.2); прерывание (смена инструмента, блокировка панелью) — фиксирует или
откатывает, «применено, но не в истории» запрещено (§3.3).

## 4. Скелет классов

```csharp
// RoomPlanner.Core (юнит-тестируемо, без Unity-специфики)
Core/Furniture/FurnitureCatalog.cs     // FurnitureCollection, FurnitureItem, реестр коллекций
Core/Furniture/FurnitureCatalogParser  // collection.json → модель, отбраковка битых записей
Core/Furniture/FurniturePlacement.cs   // Solve(), back-to-wall snap, FitScale(), квантование yaw

// RoomPlanner.App
Furniture/FurnitureController.cs       // ITool: Id="furniture", IconId="furniture", Tabs Place/Move
Furniture/FurnitureLoader.cs           // glTFast: item → инстанс; кеш в памяти + на диске, бюджет
Furniture/FurnitureItemView.cs         // поставленный предмет: Selectable(Kind=Furniture),
                                       // ISettingsProvider (size/yaw/лицензия), владение мешами
Furniture/OnlineCatalogSource.cs       // v2 (#74): Poly Pizza API → скачивание в кеш-коллекцию

// Editor/Setup
Editor/Setup/SetupFurnitureTool.cs     // префабы, ретикл, призрак, wiring
Editor/FurnitureCatalogBuilder.cs      // сборка манифестов паков (bbox, Tris) + кураторские размеры
```

Загрузка — официальный пакет `com.unity.cloud.gltfast` (не свой ридер: экономим код и
сразу получаем путь к онлайн-скачиванию). Один загрузчик обслуживает и бандл
(`jar:file://` на Android), и дисковый кеш.

Персист (#73): `ProjectFurniture { Id, Collection, Item, Position, Yaw, Scale, Anchor }`
в `ProjectData`; отсутствующий пак при загрузке → плашка-заглушка с предупреждением,
объект не теряется молча.

## 6. Осознанно отложено

- **Правка предмета** (resize, смена материала/цвета) — v1 ставит модель как есть.
- Counter-якорь (предмет на предмете) и стеки кухонных модулей.
