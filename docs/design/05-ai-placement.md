# 05 — AI-расстановка мебели (AI Placement) 🧭

- Пользователь голосом/текстом: «поставь в СЗ-угол диван 1.2×2 м».
- В Claude передаём **room-JSON** (стены/углы с координатами, свободная площадь) +
  запрос; Claude через **structured output** (`output_config.format` + JSON-схема)
  возвращает валидированный объект размещения (тип, габариты, якорь-угол, offset,
  поворот, «вдоль стены», model_id из каталога).
- Приложение спавнит **примитив-короб** нужных габаритов у реального угла/стены; после
  подтверждения — заменяет на **glTF-модель** из каталога (рантайм-загрузка glTFast).
- Модель `claude-opus-4-8`; вызов сетевой (1–3 c), не покадровый; онлайн-функция.
- Простые правки («подвинь на 10 см») — локально, без LLM.
