# 17 — Пол как замкнутый контур (и привязка стен к нему) 🔜

Сейчас пол — прямоугольник по двум углам. Нужен **произвольный замкнутый контур**: реальные
квартиры не прямоугольные, а главное — контур пола становится **опорой для стен**: их вершины
привязываются к его углам и рёбрам. Это «Фаза C» из [11-object-operations](11-object-operations.md),
поднятая в приоритете по запросу.

Сквозной принцип неизменен ([00-overview](00-overview.md)): параметры → процедурный меш, без CSG.
Свод правил кода — [12-coding-rules](12-coding-rules.md). Карта владения файлами —
[14-modularity](14-modularity.md).

## Зачем именно контур

1. **Форма помещения.** Г-образные и эркерные комнаты не описываются прямоугольником.
2. **Опора для стен** (главное). Контур пола — это то, по чему человек ведёт стены. Углы и рёбра
   контура попадают в общий `SnapFinder`, и стена садится на край пола так же, как на другую стену.
3. **Задел под комнаты.** Контур пола и замкнутый контур стен (`WallGraph.FindClosedLoops`) —
   два источника одного и того же понятия «комната» (Фаза E, [09](09-project-structure.md)).

## Модель данных

```csharp
// RoomPlanner.Core — чистая геометрия, без Unity-обвязки кроме Vector3
class FloorOutline {
    List<Vector3> Points;      // по контуру, на одном уровне (Y = Level)
    float Level, Thickness;
    // holes[] — отложено, см. «Что откладываем»
}
```

- Прямоугольник — **частный случай** контура из 4 точек. Существующий `Build(a, b, …)` остаётся
  и строит такой контур: старые вызовы и тесты не ломаются.
- Точки хранятся в **порядке обхода**; ориентация (CW/CCW) нормализуется при построении, чтобы
  верх всегда смотрел вверх (правило 1.1: winding наружу — иначе пик проваливается сквозь пол).

## Триангуляция: ear clipping в Core

Произвольный простой многоугольник нельзя нарезать «квадами». Нужен `Core/Polygon.cs`:

| Функция | Зачем |
|---|---|
| `SignedArea` / `IsClockwise` | нормализация ориентации |
| `Triangulate` (ear clipping) | верх и низ плиты |
| `Contains` (point-in-polygon) | привязки, будущее авто-определение комнат |
| `IsSimple` (само-пересечения) | «грязный» ввод MR: контур-восьмёрка не должен молча давать мусор (правило 1.3) |

Боковые грани — по рёбрам контура, наружу.

## UX рисования

- **Триггер** — добавить точку контура (как у стен).
- **Замкнуть**: клик по первой точке (в радиусе снапа) **или** `B`. Меньше 3 точек — отмена.
- Превью: полилиния по поставленным точкам + «резинка» к курсору + подсветка первой точки,
  когда её касание замкнёт контур.
- Точки ложатся на текущий `Level` (как сейчас), привязки — общие (`SnapFinder`).

## Правка

- **Ручки углов** — переиспользуем механику из Фазы B5: `FloorHandles : IHandleProvider`.
  Тянешь угол — плита перестраивается; коллайдер перепекается один раз на отпускании (правило 4.2).
- Инспектор выбранной плиты (через `ISettingsProvider`, как у стен): Level, Thickness.
  **Расцепить с `WallThickness`** — сейчас пол берёт толщину стены, это ошибка.
- Вставка/удаление вершины — отложено (см. ниже).

## Привязка стен к полу — ради чего всё

`WallController` уже кормит `SnapFinder` кандидатами. Добавляем ещё один источник: **углы и рёбра
контуров всех видимых плит**. Никаких новых механизмов — та же политика «углы бьют рёбра».
Тумблеры `Cor`/`Edg` управляют этим так же, как для стен.

## Что откладываем осознанно

- **Дыры в плите** (лестницы, шахты) — нужны для MEP/многоэтажки, но не для привязки стен.
- **Вставка/удаление вершины контура** — сначала базовая правка углов.
- **Авто-пол из замкнутого контура стен** — обратная задача, Фаза E.
- **Не-плоский контур** (ступени внутри одной плиты) — нет.

## Декомпозиция

- **C1** — `Core/Polygon.cs`: ориентация, площадь, ear-clipping, point-in-polygon, проверка на
  само-пересечения + EditMode-тесты (включая невыпуклый и «грязный» ввод).
- **C2** — `Floor` строится из контура (прямоугольник = 4 точки), winding наружу для верха, низа
  и боков + тесты на нормали каждой грани.
- **C3** — `FloorController`: рисование контура (замыкание по первой точке / `B`), превью.
- **C4** — правка: `FloorHandles` (ручки углов) + инспектор плиты (Level/Thickness, **расцепить**
  толщину от стен), всё через команды undo.
- **C5** — стены привязываются к углам и рёбрам контуров полов.
- **C6** — (позже) дыры в плите.

Проверка на каждом шаге — `driver.mjs test All`; C2–C4 меняют состав рига → `setup`.
