# 01 — Измерительные инструменты (Measure) ✅ 🔜

- **Рулетка** (✅ скелет): луч по геометрии комнаты (`Physics.Raycast` по коллайдерам
  EffectMesh — не зависит от версии MRUK API) → точка A → точка B → расстояние (м/см)
  с линией и подписью. Ввод развязан (контроллер / hand tracking позже).
- **Уровень** (🔜): отклонение поверхности от вертикали/горизонтали в градусах —
  нормаль уже возвращается из `SceneRaycaster.TryRaycast`.
- **Редактирование размеров в см** (🔜): числовой ввод, привязанный к параметрам объектов.

Реализация: `Assets/RoomPlanner/Scripts/Measure/*`.
