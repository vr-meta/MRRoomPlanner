# 07 — Слои и инженерные сети (MEP) 🧭

Единый каркас **слоёв** и общих примитивов, поверх которого работают электрика,
отопление и сантехника. Разные сети — это разные **слои** с одинаковыми механизмами:
точечные **элементы (Fixture)** и **трассы-сплайны (RouteSpline)** + автоматический
**расчёт метража/смета**.

> Тот же принцип: элементы и трассы — параметрические данные, привязанные к стенам/полу/
> потолку; визуализация и расчёт генерируются из них.

## Система слоёв (Layers)

- Каждый элемент/трасса принадлежит слою: `Interior` (мебель), `Electrical`, `Heating`
  (отопление), `Plumbing` (сантехника), `Blueprint`, `Structure` (стены).
- **LayerManager:** включение/выключение видимости, режим **solo/изоляция** (виден один
  слой), прозрачность, свой цвет слоя. Взаимодействовать можно только с активным слоем.
- Так смотрим по отдельности: где трубы отопления идут от котла; где в ванной трапы и
  разводка; где электрика — не мешая друг другу.

## Общие примитивы

```csharp
enum ServiceLayer { Interior, Electrical, Heating, Plumbing, Blueprint, Structure }

class Fixture {                  // точечный элемент: розетка, радиатор, трап, светильник…
    ServiceLayer layer;
    string catalogId;            // тип из каталога слоя
    WallFace wall; float alongMeters; float heightMeters;  // на стене
    Vector3 point;                                         // на полу/потолке
    int systemId;                // цепь / контур / стояк, к которому относится
}

class RouteSpline {              // трасса: кабель / труба отопления / труба воды
    ServiceLayer layer;
    string materialId;           // тип: сечение кабеля / диаметр трубы
    List<Vector3> controlPoints; // привязаны к стенам/полу/потолку
    bool orthoAuto;              // авто ортогональная прокладка ↔ ручной сплайн
    float Length();              // длина по сплайну
}
```

- Трассы — **сплайны** без детализации фитингов: достаточно показать «как идёт» и
  посчитать длину.
- Привязка к поверхностям и режимы авто-орто / ручной — общие для всех сетей.

## Расчёт метража и смета (общий движок)

```
Длина по типу = Σ длин сплайнов слоя (по materialId)
              + запас на подключение в точке (наценка на элемент)
              + общий запас %  → округление до бухты/хлыста
```

Итог — **BOM по слою:** метры по типам (кабель по сечению; труба по диаметру),
количество элементов. Сохраняется в проект (JSON), экспорт в отчёт.

## Электрика (слой Electrical)

- Элементы: **розетка, выключатель, светильник** (обычная лампочка: `Light` + модель),
  распаячная коробка, **щиток**. Пресеты высот (розетка ~30 см, выключатель ~90 см).
- Трассы: кабель от щитка к точкам; группировка в **цепи** (свет 1.5 мм² / розетки
  2.5 мм²), каждая цепь — свой автомат. Авто-орто: горизонтали на стандартных высотах +
  вертикальные спуски.
- Смета: метраж кабеля по сечению + запасы; кол-во точек и автоматов.

## Отопление (слой Heating)

- **Радиаторы** — элементы на стене (обычно под окном): размер/секции, высота от пола;
  грубая оценка мощности опц.
- **Тёплый пол** — **зона на полу** (как зона отделки) + змейка-сплайн; длину трубы
  оцениваем по площади и шагу укладки (`площадь / шаг`) либо по длине нарисованного
  сплайна. Грубо.
- **Трубы** — сплайны от **котла**/коллектора к радиаторам и контурам тёплого пола.
- Смета: метраж трубы по диаметру + запасы; кол-во радиаторов и контуров.

## Сантехника (слой Plumbing)

- Элементы: **трапы** (floor drains), унитаз/раковина/ванна и т.п. (точки).
- **Трубы** — сплайны: подача воды и канализация. Без детализации фитингов; уклон слива
  при желании отметить, но подробно не заморачиваемся.
- Смета: метраж труб по диаметру (подача/слив) + кол-во приборов и трапов.
