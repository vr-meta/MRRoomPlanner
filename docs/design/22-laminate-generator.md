# 22 — Генератор ламината (паттерны из досок) + карты нормалей 🔜

**Задача.** Из потайловых текстур одной доски (D:\Maps: 18 уникальных дубовых досок,
4096×684 ≈ 1.2×0.2 м, наборы diffuse/normal/roughness/reflection) собирать **бесшовные
тайлящиеся карты пола** с раскладками: палуба (deck), ёлочка (herringbone),
шашечка (basket), позже — французская ёлочка (chevron). Цвет/контраст доски —
**запекаются заранее** как варианты каталога (натуральный, серый, тёмный орех,
белёный). Попутно шейдер получает **опциональные карты нормалей** — общий механизм
и для будущих кирпичей/штукатурки (issue #9).

## Принципы

- **Запекание в редакторе, не в рантайме.** Quest не потянет композитинг 4К в кадре;
  раскладка и цветокор — офлайн, на устройство едут обычные тайлящиеся текстуры,
  неотличимые от остального каталога (FinishLibrary → MPB → LitVertexAO).
- **Раскладка — чистая математика в `RoomPlanner.Core`** (`LaminateLayout`), полностью
  юнит-тестируемая: паттерн → список квадов досок. Растеризация (GPU blit) — тонкий
  Editor-слой.
- **Источники не в git.** D:\Maps — пользовательский набор (лицензия не CC0), в репо
  не попадает. Запечённые PNG — в `Assets/RoomPlanner/Textures/Laminate/`, тоже в
  .gitignore (как весь Textures/); воспроизводятся меню **RoomPlanner → Bake Laminate**
  (headless: `CiTools`-совместимый статический метод). Нет D:\Maps → warning и скип,
  как с Download Textures.
- **Нормали опциональны для всего каталога**: у ламината есть, у старых 39 материалов
  нет — параллельный массив `normalMaps` в `FinishLibrary` с null-ами.

## Модель данных

### Core: `LaminateLayout` (новый файл `Core/LaminateLayout.cs`)

```csharp
enum LaminatePattern { Deck, Herringbone, Basket }   // + Chevron позже

struct PlankQuad {
    Vector2 Center;      // центр в UV тайла [0..1]
    Vector2 Size;        // размер в UV тайла
    float   RotationDeg; // 0 / 90 (Chevron: ±45)
    int     SourceIndex; // какая из N исходных досок
    bool    Flip;        // разворот доски на 180° (разнообразие)
    float   CropU0, CropU1; // какой отрезок доски использован (для «подрезанных» досок)
}

static class LaminateLayout {
    // tileMeters — физический период тайла (квадратный), plankL/plankW — метры.
    // seed — детерминированная псевдослучайность выбора досок (без Math.random).
    static List<PlankQuad> Generate(LaminatePattern p, float tileMeters,
                                    float plankL, float plankW, int sources, int seed);
}
```

Доска 1.2×0.2 м (L=6W) — все три паттерна v1 имеют квадратный период:
- **Deck** — 6 рядов по 0.2 м, сдвиг рядов на L/3; период 1.2×1.2 м (6 квадов).
- **Herringbone 90°** — сетка клеток W с периодом **2n = 12 клеток = 2L = 2.4 м**
  (n = L/W = 6): H-доски лесенкой с левым нижним углом `(y + 12i, y)`,
  V-доски в колонке `c` стартуют с ряда `y ≡ c + 1 (mod 12)`; 12 H + 12 V = 24 квада,
  покрытие клеток без дыр и наложений (проверяется тестом).
- **Basket** — квадраты 0.6×0.6 м из 3 полудосок 0.6×0.2 (CropU 0..0.5 / 0.5..1),
  направление чередуется шахматно; период 1.2×1.2 м (12 квадов).

`Size` квада — **осевой футпринт** (все повороты 0/90 → прямоугольники выровнены по
осям), `RotationDeg` говорит запекалке, как ориентировать текстуру доски в футпринте.

Бесшовность: квады, пересекающие край тайла, при растеризации рисуются с
wrap-дубликатами (±1 по U/V). Инварианты (тесты): полное покрытие [0..1]² без
дыр/наложений (сеточная проба), детерминизм по seed, чередование направлений
паттерна, CropU в [0..1].

### Editor: `LaminateBaker.cs` (новый, `Scripts/Editor/`)

- Источник: `D:\Maps` (константа + возможность переопределить env-переменной
  `RP_LAMINATE_SRC` для других машин). Читает `01_Oak_texture_{diffuse,normal}_NN.jpg`.
- **CPU-композитинг** (не GPU-блит — детерминированно и без скрытых шейдеров):
  выход 2048×2048; на каждый квад — заливка пикселей его футпринта (плюс wrap-копии
  ±1) билинейным сэмплом доски (`GetPixelBilinear`, crop + flip):
  - diffuse: сэмпл + **цветокор варианта** (tint-lerp, desaturate, brightness,
    contrast — параметры пресета, в sRGB);
  - normal: тот же сэмпл, но XY тангент-нормали **поворачивается вместе с доской**
    (90° → (−ny, nx), flip → отрицание), иначе рельеф «смотрит» не вдоль доски.
    Цветокор к нормалям не применяется. Непокрытые из-за float-огрехов одиночные
    пиксели лечатся соседом; больше 2048 дыр = ошибка раскладки, лог об ошибке.
- Пресеты цвета (bake-time): `natural` (без изменений), `grey` (desat 0.65, tint
  #B8B4AC), `dark` (tint #6B4A2F, contrast 1.1), `bleached` (lerp к #E8E2D8, desat 0.5).
- Карта нормалей **одна на паттерн** (не зависит от цвета) → на диск идёт:
  3 паттерна × 4 цвета diffuse + 3 нормали = **15 PNG 2К**.
- Импорт-настройки: Repeat, mips, aniso 4, max 2048; нормали — `TextureImporterType.NormalMap`.
- Именование: `lam-<pattern>-<color>.png`, `lam-<pattern>-normal.png`.

### Каталог и рендер

- `FinishLibrary`: + `Texture2D[] normalMaps` (null у большинства);
  `TryGet(..., out Texture2D normal)` перегрузка. `SetupPaintTool` добавляет
  12 записей ламината в категорию **Floors** (tile 1.2, gloss 0.35) из таблицы
  `LaminateBaker.Baked`; нормаль подцепляется по id.
- `Selectable.ApplyVisual`: если у финиша есть нормаль → `_mpb.SetTexture(_BumpMap)`
  + `_mpb.SetFloat(_HasBump, 1)`.
- `LitVertexAO`: `_BumpMap` + `_HasBump` (float, cbuffer). Тангентов в наших мешах
  нет и не появится — TBN строится в фрагменте **по производным** (cotangent frame,
  Schüler): `ddx/ddy(positionWS, uv)`. Ветка под юниформ-if (`_HasBump > 0.5`) —
  когерентно, на Adreno бесплатно при выключенном флаге. Работает и для стен
  (кирпичи, issue #9) без изменения билдеров.

## UX

Ничего нового: варианты ламината — обычные чипы в табе **Floors** инструмента Paint
(категория отдаёт их через `IdsOf`), Tile W/H и Gloss работают как у всех. Runtime-
подстройка контраста/оттенка отдельными степперами — **осознанно отложена**: цветовые
варианты запечены заранее (выбор пользователя), а generic-tint поверх текстуры уже
есть в модели (`SurfaceFinish.Color`), UI к нему добавим при необходимости.

## Осознанно откладываем

- **Chevron (45°)** — период не квадратный без подрезки, отдельная задача.
- **Roughness/reflection-карты** — шейдер пока со скалярным Smoothness; карта
  шероховатости — вместе с issue #9.
- **Runtime-цветокор** (степперы contrast/hue в Paint) — если запечённых вариантов
  не хватит.
- Другие породы дерева — источник один (дуб); структура именования готова к `02_*`.
