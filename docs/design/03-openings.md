# 03 — Проёмы: двери и окна 🔜

## Модель: проём — параметр стены (не булев вырез)

```csharp
enum OpeningKind { Door, Window }
class Opening {
    OpeningKind kind;
    float distanceFromStart;  // позиция вдоль стены, см от конца
    float width, height;      // размеры проёма
    float sillHeight;         // низ от пола: дверь = 0, окно ≈ 90 см
    // глубина = толщина стены; опц. рамка/откосы
}
```

Проём хранится в `WallSegment.openings` — привязан к стене, едет вместе с ней.

## Генерация меша — «панелизация» (без CSG)

Стену вокруг проёма строим из сплошных боксов:
**левый/правый простенок**, **притолока** сверху, для окна — **подоконная часть** снизу.
Несколько проёмов → больше простенков. Сквозь проём видно passthrough (там ничего не
рисуем).

## UX

- Навёл луч на грань → инструмент «дверь»/«окно» → клик ставит проём (snap по стене).
- Числовая панель: `ширина / высота / низ от пола / позиция вдоль стены` в см.
- Пресеты (дверь 900×2100, окно 1200×1400 при подоконнике 900).
- Ручки: ширина/высота/подоконник; шаг привязки.

## Валидация

Проём в пределах стены; мин. простенок (напр. ≥5 см); высота ≤ высоты стены минус притолока.
