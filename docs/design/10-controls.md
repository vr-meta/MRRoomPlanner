# 10. Карта кнопок (controls)

Единая раскладка ввода для всех инструментов. Указатель — **правый** контроллер
(луч от `rightControllerAnchor`), **навигация — левая рука** (`21-locomotion.md`);
меню — **летающая мини-панель снапов** + плавающий инспектор (обе руки свободны —
фидбек со шлема 2026-08-11: на руке ничего не живёт, руки нужны рулетке).
Реализация: `MeasureInput`
(`Assets/RoomPlanner/Scripts/Measure/MeasureInput.cs`). Грипы читаются с **любой**
руки; триггеры с 2026-08-10 разделены: правый — Confirm, левый — телепорт-портал.

## Правый контроллер (рука-указатель)

| Кнопка | Действие | Где |
|---|---|---|
| **Index Trigger** | Поставить точку / **выбрать объект** / **потянуть вершину** (ручка перехватывает клик у объекта) / начать перетаскивание (удержание) | Select, Measure, Walls, Menu |
| **Grip (side)** | Модификатор привязки (Measure — ось; Walls — угол 15°). **Над заголовком инспектора** — таскать плавающую панель | Measure, Walls, Inspector |
| **Thumbstick ↑/↓** | Глубина курсора в воздухе; в **Blueprint («Plan»)** — смещение плана по Z | Measure, Walls, Blueprint |
| **Thumbstick ←/→** | Blueprint — смещение плана по X; иначе *свободно* | Blueprint |
| **Thumbstick click (R3)** | **Предыдущий инструмент** (мгновенный возврат без прицеливания) | Все |
| **A (Button.One)** | **Радиальное меню инструментов** — открывается по нажатию (без удержания). Прежний «тап = телепорт, удержание = радиал» убран 2026-08-15 (#87): путешествие целиком за порталом на триггере, и одна кнопка больше не значит двух вещей | Все |
| **B (Button.Two)** | Удаление/отмена **только по цели** (слепых LIFO-удалений нет — UX v2 P0.3): Select — удалить выбранное (отменяемо); Measure — удалить измерение под прицелом / отменить превью; Walls — завершить цепочку; Blueprint — отменить калибровку. **B «по пустоте» = возврат в Select** (Esc-семантика) | Все |

## Левый контроллер (рука-меню)

| Кнопка | Действие | Где |
|---|---|---|
| **Index Trigger (удержание)** | **Телепорт-портал** (`21-locomotion.md`): баллистическая арка от левого контроллера + кольцо на цели (плита пола / ступень); **отпускание — телепорт** (модель к ногам, undo). Невалидная цель — тусклая арка, отпускание молчит | Все |
| **Thumbstick ↑/↓** | **Плавный ход** вперёд/назад вдоль взгляда (2 м/с, двигается OVRCameraRig); при открытом радиале — флик выбора сектора | Все / Радиал |
| **Thumbstick ←/→** | **Snap turn 45°** вокруг головы (порог 0.6, ре-арм в центре, тик хаптики; стрейф заменён поворотом) | Все |
| **Thumbstick click (L3)** | **Радиальное меню инструментов** — дублирует A (основной путь). Механика (`20-ui-design-system.md` §1): открыть по взгляду (0.6 м, world-lock); **основной выбор — курсор на секторе + триггер** (ретикл виден на колесе); альтернатива — флик стиком >0.55 хода, отпускание быстрее 400 мс; B / центр — отмена. 12 фиксированных секторов (4 — резерв) | Все |
| **Мини-панель снапов (Snap strip)** | **Летающая** (v4, не на руке): спавнится у взгляда внизу-слева (0.55 м) один раз; дальше **держит своё смещение от пользователя** — при ходьбе лениво едет следом (дедзона 0.35 м — кивки головы её не двигают), **но к взгляду не прыгает никогда**: запарковал сзади — остаётся сзади. **Grip по панели — перетащить/запарковать**; смещение перезакрепляется. Вдвое меньше прежней (0.31×0.115 м): 5 иконок-тумблеров привязок (LED = ON) + **gear** (страница Rendering в инспекторе: Vertex AO, тени, Edges) + пассивный **чип текущего инструмента** + хинт «Tools: press A» | Menu |
| **X (Button.Three)** | **Undo** (глобально, стек команд `EditHistory`) | Все |
| **Y (Button.Four)** | **Redo** (глобально) | Все |
| **Grip** | Дублирует правый (модификатор привязки; читаем обе руки) | — |
| **Menu (Start, ≡)** | **Радиальное меню инструментов** — дублирует A/L3 (короткое нажатие доступно приложению; длинное — системное) | Все |

## UI: радиал (A/L3) + летающая мини-панель снапов + плавающий инспектор v2

Поверхности после рефакторинга UI (`20-ui-design-system.md`):
- **Радиальное меню (A / L3)** — переключение инструментов, 12 секторов-компаса.
- **Летающая мини-панель Snap** — тумблеры привязок иконками + gear (Rendering) +
  чип текущего инструмента; grip — запарковать; следует за пользователем лениво.
- **Плавающий инспектор v2** — сетка 6 мм, 12 типов виджетов (Stepper/Slider/Segmented/
  Select/Toggle/Numeric/Swatch/Action/Readout/Progress/Header + Tabs), попапы
  (Select-список, numpad, свотч-сетка) — один модальный слой, B/клик-мимо закрывает.
  **grip по заголовку — таскать/парковать**; слайдер: триггер = драг, **грип = точный
  режим ×0.1**; деструктивные кнопки — удержание 0.5 с (заливка Danger).
- **HUD у прицела** (план на будущее) — окраска по инструменту, подсказки, бейдж размера.

**Инспектор Walls:** Thickness (слайдер), Height (слайдер), Angle step (степпер),
Offset/Corner/Place (сегменты — все опции видны).
**Инспектор Floor:** Level (numeric → numpad), Thickness (слайдер).

### Инструмент Floor — контур (Фаза C)

Контур, замкнутый **целиком внутри** уже существующей плиты того же уровня, становится
**дырой** в ней (лестница, шахта) — отдельного режима не нужно.

Пол рисуется **замкнутым контуром**, а не двумя углами: **триггер** ставит угол, клик по
**первому углу** (радиус 15 см, прицел к нему подтягивается, превью замыкается в кольцо)
строит плиту. **B** — замкнуть, если углов уже ≥3; иначе отменить начатый контур; на пустом —
вернуться в Select (Esc-семантика).
**Инспектор Plan (Blueprint):** Plan scale (слайдер), Rotation (±5°, степпер),
**Plan file** (Select-список изображений из Download/Pictures шлема и папки приложения),
**Load plan** (кнопка), **Calibrate** (кнопка; 2 пары точек: A на плане → A в комнате →
B на плане → B в комнате; масштаб+поворот+смещение одним действием; B — отмена),
Status (readout). Смещение — стиком. Разрешение на чтение изображений запрашивается
при первом входе в инструмент.
**Инспектор Paint («Pnt», покраска — `04-surfaces-materials.md` v1.2):** табы
**Color / Walls / Floors / Tiles / Ceiling**; Color — сетка 8 пресетов + Gloss;
текстурные табы — свотчи текстур (CC0 + запечённый ламинат) + степперы **Tile W/H**,
**Rotate** (15°-шаги, развернуть ламинат/плитку)
(±25 см, «auto» = тайл каталога, H по умолчанию = квадрат) + **Gloss**
(auto/0–100 %, шаг 10 %); Segmented **Apply: Part | Whole** (дефолт Part) —
Part у стены красит **сторону** (#34), у плиты — **комнату под прицелом**
(кольцо из графа стен, плита режется вложенной под-плитой; #52, `24-rooms.md`);
триггер по стене/полу/лестнице — применить (отменяемо),
**Original look** (кнопка-ластик) — снять отделку с объекта под прицелом.
Страница **Rendering** (gear на панели снапов): Vertex AO, **Sun shadows**
(карта теней), **Cast shadows (all)** (отбрасывание теней всеми элементами),
**Edges** (обводка рёбер у всех элементов, у которых она есть — сейчас стены;
по умолчанию выкл — фидбек 2026-08-13: обведённые стены выбивались из сцены).
SSAO снят после трёх проверок на девайсе (мазня в Multiview — issue #15).
B — возврат в Select.
**Инспектор Import («Imp», IFC из Revit — `18-ifc-import.md`):** **IFC file**
(Select-список `.ifc` из Download/Documents шлема и папки приложения), **Load IFC**
(кнопка; статус — readout «Nw Ms (K skip)»), **Storey** (Select: All/L1/L2/… — фильтр
видимости по этажам), **New project** — деструктивная кнопка (удержание 0.5 с).
Весь импорт — один Undo. **Триггер — маркер места** (#60): кольцо на поверхности под
лучом, «Load IFC» сажает здание туда нижним центром футпринта; **B** — снять маркер,
на пустом — возврат в Select.
**Инспектор Projects («Proj», #58 — `06-project-format.md` §«Проекты v1»):** Readout
**Current**, **Project** (Select-список; открытый помечен «•»), **Open** (автосейв
текущего → загрузка выбранного), **Save** (первый раз выделяет имя «Project N»),
**New project** и **Delete selected** (деструктивные, удержание 0.5 с), Status
(readout). Слот радиала — бывший резерв Heating. B — возврат в Select.

**Инспектор Electric («Elec» — `19-electrical.md`):** **табы с иконками**
Outlet / Switch / Wire / Box / Panel (розетка/клавиша/провод/распредкоробка/щиток),
ниже — ряды активного таба: Outlet — Posts (1–5, степпер), Height (слайдер); Switch —
Keys (1–3), Height; Wire — Cable (сегменты 3x1.5 | 3x2.5), Route (сегменты
Ortho | Free); Box — без настроек (подсказка-readout); Panel — Reserve % (слайдер).
Розетка/выключатель/щиток ставятся **триггером** по грани стены, высота жёстко снапится
к пресету режима (грип = свободная вертикаль); **коробка (Box) — по стене ИЛИ потолку,
высота свободная**; промах мимо поверхности точку не ставит. Провод ведётся **руками**:
триггер кладёт точки по стенам/потолку; Ortho вставляет одно колено (горизонталь на
высоте верхней точки) — **на потолок сам не уходит** (v2); курсор ближе 10 см к
терминалу фикстуры прилипает и записывает привязку; **клик по свободному концу
существующей трассы подхватывает её** (#81) — рисование продолжает ТОТ ЖЕ провод
(одна запись undo на всё продолжение; конец с привязкой к фикстуре не подхватывается);
**клик по терминалу завершает
трассу** (щиток, коробка, розетка); **B** — завершить трассу (≥2 точек) / отменить
начатую / на пустом — возврат в Select. Смена режима или инструмента с начатой трассой
= авто-финиш, не потеря. Метраж по типам кабеля — в описании выбранного щитка (Select).

**Инструмент Plumb («Plumb», `30-plumbing.md`):** табы **Riser / Pipe / Outlet / Drain**
(слот радиала 10 — бывший резерв Plumbing, акцент #4DA6FF). *Riser* — **триггер по полу**
ставит вертикальную D110-трубу от пола до потолка (потолок — луч вверх, фолбэк
Level+WallHeight); ряды: readout Stack, Reserve % (слайдер, смета). *Pipe* — Diameter
(сегменты 110 | 50 | 40), Route (Ortho | Free); точки кладутся **триггером по стенам,
ПОЛУ и потолку** (в отличие от провода пол валиден — канализация лежит по полу); Ortho
вставляет колено с горизонталью на высоте **нижней** точки (магистраль по полу, зеркало
провода). Снапы конца: терминал вывода/трапа → **ось стояка на любой высоте** (тройник,
связь по id — стояк двигается, конец едет за ним) → свободный конец трубы того же
диаметра (продолжение той же трубы, одна запись undo — паттерн #81). Клик по
терминалу/стояку завершает трассу; старт от вывода задаёт диаметр (Toilet → 110,
Sink → 50); **B** — завершить (≥2 точек) / отменить / возврат в Select. *Outlet* — Type
(Toilet | Sink), Angle (90° | 45°), Height (слайдер, см): **триггер по грани стены**,
высота снапится к пресету вида (Toilet 18 см, Sink 45 см; грип = свободная вертикаль),
ghost-превью, пересечение с другой фикстурой — отказ; **Angle: 90° / 45°↓ / 45°↑**
(#114). *Drain* — **триггер по полу**, трап 150×150 заподлицо с полом, боковой порт
D50 = терминал. **Правый стик ←/→ крутит превью** вывода (±75° вокруг вертикали,
чтобы косой отвод смотрел на стояк) и трапа (свободно, портом к трассе); грип
квантует по 15°, детент-тик хаптики (#115). При постановке видны **размерные
привязки** (#113): линии+см до ближайшей стены (у угла — до двух), при Grd-снапе
позиция квантуется на 5 см. Select: драг фикстуры
везёт привязанные концы труб; у трубы — ручки точек; смета по диаметрам + колена
90°/45° — в описании выбранного **стояка**.

**Инструмент Furniture («Furn», `27-furniture.md`):** табы **Place / Move**.
*Place* — Select **Collection** → Select **Category** → Select **Item**, степпер
**Rotate** (15°), тумблер **Snap to wall**, ридауты размера и лицензии пака.
Прицел даёт призрачный прямоугольник габарита: зелёный — встанет, красный (Danger) —
поверхность не подходит якорю предмета (диван на стену, подвесной шкаф на пол);
**триггер** ставит предмет одной undo-записью, **B** — возврат в Select.
*Move* — прицелиться в мебель (каталожную **или импортированную из IFC**), **удержание
триггера** везёт её по её же плоскости пола, отпускание пишет одну команду перемещения;
**B** у наведённого предмета — удалить (отменяемо).
**Поворот — правый стик ←/→**: крутит призрак в Place и наведённый/несомый предмет в
Move (90°/с, тик хаптики каждые 15°); **грип** квантует угол по 15°. Весь поворот —
одна запись истории, пишется при возврате стика в центр. Степпер **Rotate** в панели —
точный дискретный путь к тому же.

**Степперы −/+ (все):** удержание триггера = автоповтор (0.4 с → 8 Гц → через 1.5 с шаг ×5);
хаптика: клик 20 мс, вход в кнопку 10 мс, детент шага 8 мс.
**Инспектор Select:** группа выбранного объекта — заголовок «Тип #id» + краткое описание (длина/размер) + подсказки. Пока read-only (per-instance правка параметров — Фаза B).

### Ручки вершин (Фаза B)

У выбранной стены появляются **ручки на её узлах** (постоянный угловой размер ~2°: не «шар»
вблизи и не точка через комнату). Тянешь ручку — двигается **узел графа**, поэтому едут все
стены на нём (угол → две, T-стык → три). Высота этажа при этом не меняется. Весь жест —
**одна** запись в undo.

### Инструмент Measure — режимы (v2, фидбек 2026-08-10)

**Hands (по умолчанию, Layout-style):** кончик рулетки = правый контроллер (+7 см);
лента и бейдж размера live; **триггер** фиксирует точку — «закрепил A, отошёл,
закрепил B»; магнит кончика к углам измерений и ближайшим поверхностям (6 см);
грип — ось; B — отменить ленту / Esc. **Кончик на существующей вершине:
удержание триггера — перетащить её до отпускания; короткий тап (<0.25 с) —
новая лента от этой вершины** (фидбек 2026-08-11). Телепорт двигает и
незавершённую ленту: закреплённая точка A остаётся на модели, а не «едет»
с пользователем. **Ray:** прежний дальний режим — луч,
триггер, стик = глубина в воздухе. Переключение — сегмент Mode в панели Measure.
Луч-поверхность в Ray-режиме видит и **собственные** стены/полы (ближайший хит),
а не только скан.

### Инструмент Select (дефолтный, Фаза A)

Наведи правый луч на стену/пол/измерение → **триггер** выбирает (зелёная подсветка), при
наведении — cyan-подсветка + вибро. **Удержание триггера** тащит объект по горизонтали
на его высоте (перемещение всего объекта; на релизе — одна команда undo). **B** — удалить
(отменяемо, объект прячется, не разрушается). **X/Y** — undo/redo. Клик по пустоте — снять
выбор. Стены/полы — на слое `Selectable` (6), поэтому не мешают лучу-поверхности при рисовании.

**Двери/ворота (issue #50, драг — фидбек 2026-08-12):** полотно — самостоятельная
цель Select: первый триггер выбирает дверь (страница Width/Height/Hinge/Swing/
**Open %**/Delete). Дальше жест по паттерну #46: **короткий тап по уже выбранной
двери — открыть/закрыть** (анимация к последнему Open %; не в undo — view-действие);
**удержание/движение — перенос проёма вдоль стены** (превью live, на релизе одна
команда undo, невалидная позиция откатывается). **B** на выбранной двери удаляет
**проём** (отменяемо). Перенос также доступен в инструменте Openings.

### Панель привязок (Snap, как в 3ds Max — тумблеры; на летающей мини-панели)

| Тумблер | Что даёт | По умолчанию |
|---|---|---|
| **Corner** | Привязка к углам/концам (стены, измерения) | вкл |
| **Edge** | Привязка к рёбрам существующих стен (T-соединения) | вкл |
| **Grid** | Привязка к сетке (шаг 5 см, по XZ) | выкл |
| **Angle** | Угловая привязка стен всегда (без grip), шаг из «Ang» | выкл |
| **Scan** | Вкл = passthrough MR со сканом комнаты (EffectMesh + примитивы Virtual Home). **Выкл = выход из passthrough**: виртуальный фон (скайбокс/сумеречный цвет) + плоскость земли под моделью — режим «пришёл проектировать от плана/импорта, а не сканировать» | **выкл** (с 2026-08-10: основной сценарий — прогулка по импортированному дому; выкл также включает плавный ход стиком) |

Grip остаётся модификатором «привязать сейчас» (ось для измерений / угол для стен), даже если тумблеры выключены.

## Принципы

- Свободный слот — это запас на будущее, не ошибка.
- Новые действия сначала вешаем на свободные слоты правой руки, затем на левую.
- Любое действие постановки/выбора — **только триггер** (не A/B), чтобы не путать.
- Модификаторы — на грип (удержание), дискретные команды — на кнопки (нажатие).
