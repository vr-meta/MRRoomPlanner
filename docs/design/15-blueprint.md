# 15 — Blueprint: чертёж на полу 🔜

**Сценарий (ядро продукта):** прийти в пустую квартиру, положить чертёж на пол,
выровнять его по комнате (масштаб/поворот/смещение или калибровка по 2 точкам) — и
строить по нему стены/полы. Ранее план был прибит к Floor-инструменту (только масштаб и
смещение, без поворота); здесь он становится **самостоятельным инструментом** со своим
состоянием (первый инструмент, добавленный по правилам `14-modularity.md`).

## Модель

Проекция плана — **подобие (similarity) на плоскости пола**: масштаб + поворот + смещение.

```csharp
// RoomPlanner.Core — чистая математика, юнит-тестируемо
struct BlueprintPlacement {
    float Scale;        // метров на единицу UV (ширина картинки в метрах)
    float RotationDeg;  // поворот плана вокруг Y
    float OriginX, OriginZ; // мировая точка UV-начала
}
static class BlueprintMath {
    Vector2 WorldToPlanUV(Vector3 world, in BlueprintPlacement p);   // для UV пола
    Vector3 PlanUVToWorld(Vector2 uv, float y, in BlueprintPlacement p);
    // Калибровка: две пары «точка на спроецированном плане → где она должна быть».
    // Решает новое подобие так, чтобы обе пары совпали (масштаб+поворот+смещение разом).
    BlueprintPlacement FromPointPairs(Vector3 fromA, Vector3 toA,
                                      Vector3 fromB, Vector3 toB, in BlueprintPlacement current);
}
```

- `Floor` получает поворот плана: UV верхней грани = `WorldToPlanUV` (метрические UV,
  как в `04-surfaces-materials.md`). Старая сигнатура `Build(...)` без поворота остаётся
  перегрузкой (rotation = 0) — существующие вызовы/тесты не трогаем.
- Изображение — `plan.png` в `persistentDataPath` (v1, как раньше); загрузка/владение
  текстурой — у `BlueprintController` (из FloorController выселяется).

## Инструмент Blueprint (палитра: «Plan»)

- **Состояние — в контроллере**, не в `ToolManager` (снимает долг из чек-листа 2g):
  scale / rotation / offset / текстура.
- **Стик** — смещение плана по XZ (как раньше в Floor, теперь только здесь).
- **Схема настроек** (инспектор, рантайм-ряды): `Plan scale` ±0.25 м · `Rotation` ±5° ·
  `Reload` (перечитать plan.png; значение — статус «ok 1024×768» / «no file»).
- После изменения параметров контроллер зовёт `FloorController.RefreshPlan()` — плиты
  пересобираются вживую (связь blueprint→floor односторонняя, задокументирована).

## Калибровка по 2 точкам (следующий шаг, BP5)

1. Инструмент в режиме Calibrate: триггер ставит точку **A′** на спроецированной
   черте плана (например, угол стены на чертеже), затем точку **A** — где этот угол
   в реальной комнате; то же для **B′ → B**.
2. `FromPointPairs` совмещает обе пары: масштаб, поворот и смещение выставляются одним
   действием. Кнопка Cancel/повтор — B.
3. Валидация: |A′B′| и |AB| больше эпсилона (~10 см), иначе игнор.
