# 24 — Комнаты из графа стен: детект колец + покраска пола по комнатам

Статус: v1 в работе (issue #52, ветка `worktree-audit-fixes`, 2026-08-12).
Контекст: одна плита на весь этаж — покраска пола красила все комнаты разом.
Обсуждение вариантов (зоны/разрез/маска) — выбраны **авто-контуры из графа стен
поверх механизма вложенных плит** (дыра + под-плита), без нового рендер-механизма.

## Модель: комната = ограниченная грань планарного графа стен

Стены уже граф (`WallGraph`): общие узлы, кольца — это и есть комнаты.

```csharp
// Core/RoomFinder.cs — чистая математика, юнит-тесты
sealed class RoomRing {
    List<Vector3> Polygon;   // осевые точки узлов кольца (v1 — центрлайны)
    float Area;              // м², по XZ
    float Level;             // высота узлов (медиана y)
}
static class RoomFinder {
    static List<RoomRing> FindRooms(WallGraph g);
}
```

Алгоритм — обход планарных граней (half-edge):
- сегменты группируются по уровню (кластеры |Δy| < 0.5 м — этажи не смешиваются),
  `Suppressed` (удалённые) пропускаются — удаление стены сливает две комнаты;
- каждый сегмент = два направленных ребра; на узле рёбра отсортированы по углу;
  следующий за (a→b) — минимальный поворот от (b→a) (стандартный face-walk);
- каждая грань обходится один раз; **неограниченная** грань компоненты — с
  максимальной |площадью| — отбрасывается; тупиковые отростки дают нулевую
  площадь и не мешают; кольца из <3 узлов или <0.3 м² — мусор, отбрасываются.

v1 сознательно: полигон — по **осевым** линиям (шов прячется под телом стены);
полигоны внутренних граней стен (со смещением на полутолщину) — v2.

## T-heal графа — предпосылка И распространение на стены

Перегородка, упёршаяся в **середину** длинной стены (типично для IFC: коридорная
стена — один IfcWall на несколько комнат), не делит её узлом: граф в точке T
разорван → кольца не замыкаются, а покраска стороны красит стену на всю длину
через несколько комнат.

`RoomFinder.SplitTJunctions(graph)`: для каждого узла — сегменты, на чьей осевой
(XZ, тот же уровень) он лежит не концом → `SplitSegmentAt` (проёмы переезжают с
сохранением мировой позиции — уже отлажено, аудит 02 §Б1). Идемпотентно, до
фикспойнта. Запуск: после импорта IFC и лениво перед поиском комнат
(`WallGraphRenderer.HealTJunctions` → Sync + rebuild затронутых).

Следствие для стен: после разреза сегмент с каждой стороны смотрит ровно в одну
комнату — **покраска стороны (#34) автоматически = покраска стены комнаты**,
отдельного механизма не нужно. Честный побочный эффект: одна длинная стена
становится двумя в выборе/BOM (CAD-корректно).

## Покраска пола по комнате («Paint room», аудит 06 §Р2)

Сегмент **Apply** в Paint обобщается: `Side | Whole` → **`Part | Whole`**
(дефолт Part): у стены «Part» — сторона (#34), у плиты — **комната под прицелом**.

Механика — вложенная плита (переиспользуем параметрические дыры):
1. Луч в плиту, scope Part → `RoomFinder` ищет кольцо, содержащее точку
   (point-in-polygon по XZ) на уровне плиты (|Level − slab.Level| < 1.5 м).
2. Полигон комнаты **вжимается внутрь на ~2 см** (митровый инсет) — кольца
   соседних комнат и границы плиты никогда не касаются (валидация дыр);
   полоска под осевой стены остаётся старой — её не видно.
3. Плита-донор получает **дыру** по инсет-кольцу, тем же контуром создаётся
   **под-плита** (та же толщина/уровень), под-плита красится выбранной отделкой.
   Всё это — **одна команда undo** (`PaintRoomCommand`: дыра + показ под-плиты +
   финиш; undo снимает дыру и прячет плиту).
4. Повторная покраска попадает уже в под-плиту: её контур ≈ кольцо комнаты
   (совпадение площадей в пределах 5 %) → красится целиком, без новой резки.
5. Комнаты нет (свободная планировка/нет стен) или дыра отвергнута валидацией →
   деградация в покраску всей плиты, как раньше.

Персист бесплатно: под-плиты — обычные `Floor` в списке `Floors` (формат v3),
финиши едут как у всех.
