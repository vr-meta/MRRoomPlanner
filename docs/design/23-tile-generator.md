# 23 — Генератор керамической плитки (кабанчик и др.) 🔜

**Задача.** Больше плитки для ванной/кухни (фидбек 2026-08-12): кабанчик (subway с
широкой фаской), квадратная сетка, ёлочка кабанчиком — в разных цветах глазури.
Керамика, в отличие от ламината (док 22), **не требует фото-исходников**: лицо
плитки — цвет + лёгкий шум глазури, характер дают широкая фаска (карта нормалей),
шов затирки и глянец. Генерируем процедурно на инфраструктуре дока 22.

## Раскладки (переиспользуем `Core/LaminateLayout`)

| Паттерн | Плитка | Раскладка | Период |
|---|---|---|---|
| **Subway (кабанчик)** | 0.2×0.1 м (2:1) | Deck со сдвигом рядов **½** (не ⅓) | 0.2 м |
| **Grid (квадрат)** | 0.2×0.2 м | новый кейс `Grid` — сетка k×k | 0.2 м (2×2 в тайле → 0.4) |
| **Herringbone** | 0.2×0.1 м | Herringbone n=2 | 2L = 0.4 м |

Изменения Core: `LaminatePattern.Grid` (ratio 1:1, минуя проверку n≥2) и параметр
`deckOffset` в `Generate` (по умолчанию ⅓ — ламинат не меняется). Тесты покрытия —
те же инварианты.

## Editor: `TileBaker`

Как `LaminateBaker`, но лицо синтезируется, а не сэмплируется:
- **Лицо**: базовый цвет глазури + пер-плиточная вариация яркости (хэш квада, ±3%)
  + мелкий шум глазури (амплитуда ~2%).
- **Затирка**: расстояние до края < ~1.2 мм → цвет затирки (тёплый серый), нормаль
  плоская, глянец не влияет (запечён в diffuse чуть темнее).
- **Фаска**: зона 1.2…15 мм (кабанчик — широкая, сетка/ёлочка — 3 мм) — плавный
  наклон нормали (полуволна), лёгкое высветление к кромке.
- Выход 1024² (период ≤0.4 м → ≥2.5 px/мм): **1 нормаль на паттерн** + diffuse на
  цвет. Цвета v1: white, cream, sage, sky, graphite, terracotta → 3×6 = 18 diffuse
  + 3 нормали в `Textures/TilesBaked/` (gitignored, восстановление меню
  **RoomPlanner → Bake Tiles**; исходники не нужны вовсе).
- Каталог: `TileCatalog` в Core (пин-тест), id `tile-<pattern>-<color>`, категория
  **Tiles** (стены И полы), gloss 0.75, tile из периода. Wiring — `SetupPaintTool`,
  нормали через `FinishLibrary.normalMaps` (док 22).

## UX

Чипы появляются в табе **Tiles** к 7 ambientCG-плиткам; Tile W/H, Rotate и Gloss
работают как у всех. Отдельного UI нет.

## Осознанно откладываем

- Гексагон/мозаика/терраццо (не прямоугольные раскладки — другой растеризатор).
- Выбор цвета затирки, произвольный цвет глазури (пока пресеты).
- Расширение ambientCG-набора (фото-плитка) — по фидбеку, отдельной пачкой.
