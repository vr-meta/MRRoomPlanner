# 08 — Импорт/экспорт (Interop) 🧭

Обмен с CAD/BIM-программами (Revit, ArchiCAD, AutoCAD) и DCC.

## Форматы обмена

| Формат | Роль | Направление |
|---|---|---|
| **IFC** (Industry Foundation Classes) | **основной формат обмена BIM** — семантические элементы (стены/окна/двери/перекрытия/помещения/MEP) | импорт ↔ экспорт |
| **DWG** (AutoCAD) | 2D-план: подложка чертежа + опц. трассировка стен | импорт |
| **glTF / glb / OBJ / FBX** | визуальные меши для DCC (3ds Max) и рендеров | экспорт (импорт как визуал) |
| **наш JSON** | источник истины (семантика проекта) | внутренний |

> `.rvt` (Revit) и `.pln` (ArchiCAD) — закрытые форматы, напрямую не читаем.
> Обмен идёт **через IFC**.

## IFC ↔ наша модель

IFC несёт объекты с параметрами → ложатся на нашу параметрическую модель, поэтому после
импорта элементы **редактируемые**, а не «немой меш»:

| IFC-сущность | → Наша модель |
|---|---|
| `IfcWall` / `IfcWallStandardCase` (ось + толщина) | `WallSegment` + узлы графа стен |
| `IfcDoor`, `IfcWindow` (+ `IfcOpeningElement`) | `Opening` (дверь/окно) |
| `IfcSlab` | пол/потолок + зоны отделки |
| `IfcSpace` | комната |
| `IfcFurnishingElement` | мебель (каталог) |
| `IfcFlowTerminal` / `IfcFlowSegment` | элементы и трассы инженерных сетей |

**Round-trip:** импортировали IFC из Revit/ArchiCAD → доредактировали у нас → экспорт в
IFC обратно.

## Чем парсить

- **`xBIM Toolkit` (Xbim.Essentials)** — .NET/C# библиотека чтения/записи IFC.
- **IfcOpenShell** (Python/C++) или **web-ifc** (WASM/TS) — если на бэкенде.
- **Рекомендация:** тяжёлый парсинг IFC делать **на бэкенде** (файлы большие), в шлем
  отдавать наш компактный JSON. Ложится на разделение «клиент Unity / бэкенд».

## DWG (AutoCAD)

- Подложка 2D-плана на пол (модуль Blueprint).
- Опц. **трассировка стен** из линий/полилиний слоя «Стены» + блоков дверей/окон.
- Подключён `autocad-mcp` — можно вытягивать слои/примитивы.

## Оговорки

- Качество импорта зависит от «чистоты» исходной модели (стандартные стены = ось+толщина
  извлекаются чисто; произвольные солиды дадут геометрию без авто-разбивки на сегменты).
- Делаем **прагматичное подмножество**: стены, двери/окна, перекрытия, помещения,
  ключевые MEP-элементы — этого достаточно для «импортировал → доредактировал».
