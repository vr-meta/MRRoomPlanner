# 16 — UX v2: целевой опыт (ревью 2026-08-09) 🔜

Обновляет устаревшее UX-ревью из 2d (оно делалось под 2 инструмента и монолитную
панель). Сегодняшний контекст: **5 инструментов** (Sel/Meas/Wall/Floor/Plan),
схемо-инспектор с per-instance параметрами, целевая сессия ~1 час в пустой квартире.
Три эксперта (эргономика/моторика · workflow pro-CAD · информационный дизайн), полные
отчёты — в истории сессии; здесь — сведённая спецификация.

## Общий вердикт

**Модель «палитра у левой руки + плавающий инспектор» остаётся** — архитектура
(реестр + схемы) масштабируется и уже окупилась. Не масштабируются три вещи:
**моторика** (несглаженная палитра, степперы без repeat, пере-центрирование
инспектора), **семантика режимов** (B несёт 4 смысла без индикации, точного ввода
чисел нет) и **визуальный язык** (зелёный = 3 разных смысла, hover/pressed/disabled
отсутствуют, hue-канал не зарезервирован под MEP-слои).

## P0 — блокеры сценария v1

1. **Калибровка чертежа по 2 точкам (BP5)** — поднять из «следующего шага» в блокер:
   текущая калибровка степперами = 30–50 действий с итерациями (поворот вокруг
   UV-origin сдвигает план); две пары точек = 4 нажатия триггера. Математика готова
   (`BlueprintMath.FromPointPairs`).
2. **Hold-to-repeat на всех степперах**: задержка 0.4 с → 8 Гц → через 1.5 с шаг ×5.
   Плюс хаптика: клик 0.6/20 мс; hover-enter 0.2/10 мс; детент шага 0.3/8 мс;
   граница диапазона — двойной тик. (Сейчас один Pulse 0.5/60 мс — «жужжание».)
3. **Семантика B**: деструктив только по цели (hover/selection) — **запретить слепые
   LIFO-удаления** в Measure/Floor; **B по пустоте = возврат в Select** (Esc-семантика,
   убирает 2 похода в палитру на каждую правку). После `FinishChain` — авто-выбор
   последней стены.
4. **Инспектор**: парковка **персистентна** (`PlaceInFront` только при первом показе
   или если панель вне 45°/дальше 2.5 м); биллборд **только yaw**; спавн 0.65 м;
   **авто-высота фона** `0.10 + rows × RowStep` (сейчас пустой квад 65×79 см блокирует
   сцену коллайдером); масштаб панели 1.8 → ~1.3 при поднятом поле шрифта (см. P1.5).

## P1 — ядро качества

1. **Ретикл — носитель режима** (вместо жёлтой сферы на все инструменты):
   кольцо Ø12 мм по нормали поверхности + точка-ядро; **цвет = слой инструмента,
   глиф = инструмент** (`ITool.AccentColor`/`ReticleGlyph` — по строке на инструмент);
   снап меняет **форму** (corner→квадрат, edge→штрих, grid→4 точки) + тик;
   **бейдж длины** при рисовании (чип 60×24 мм, фон #10131AE0) — сейчас «скетчер слеп»;
   **строка-подсказка жеста** («Trigger: place · B: finish») из `ITool.HintText`,
   показывается 3 с после смены инструмента.
2. **Палитра — стабилизация**: lazy-follow (lerp τ≈0.12 с + мёртвая зона 1.5 см),
   биллборд с порога 5°; гистерезис ховера (+15% коллайдера); зазор кнопок ≥20% ширины
   (шаг 0.0485 → 0.056); **гейтинг по наклону контроллера** (dot>0.6 показ / <0.45
   скрытие, fade 150 мс) — решает и визуальный шум, и случайную блокировку инструмента
   левой рукой; menu-хиты дальше 1.2 м не считать `overMenu`.
3. **Состояния кнопок** (яркость и форма, не hue): hover — заливка #3A4256 + рамка
   #7FD9FF, scale 1.06; pressed — scale 0.97 + вспышка 80 мс; disabled — текст 25%
   альфы, без ховера/хаптики; **радио ≠ тумблер**: активный инструмент —
   инвертированная кнопка (светлый фон, тёмный текст), тумблер ON — штрих + LED-точка.
4. **Подсветка объектов — рим/лерп вместо полной перекраски** (`Color.Lerp(own, c, 0.3)`
   минимум; правильно — fresnel-рим): полная заливка `_BaseColor` уничтожит покраску
   стен — главную будущую фичу. Отдельный канал `_LayerTint` под цвет слоя.
5. **Типографика**: floor шрифта рядов ≥0.78×size.y (≈0.95° на 60 см; сейчас 0.34° —
   ниже порога читаемости); три роли (Title 1.2° / Row 0.95° / Hint 0.8°) вместо
   per-label автосайза; панели непрозрачные + рамка-рим #FFFFFF22 (силуэт в тёмной
   комнате); дедуп `MakeText` (SetupAssets vs InspectorPanel разъехались).
6. **Системные цвета навсегда**: hover/target **#7FD9FF**, selected/active **#55E6A0** —
   и запрет использовать их как цвета слоёв. Линию измерения увести с зелёного.
7. **Stick-scrub чисел**: луч на ряде значения → стик ←/→ = ±1 см (10 Гц, разгон ×5,
   с грипом ±1 мм) — стик над меню свободен, ноль новой геометрии.

## P2 — следующий горизонт

1. **`SettingKind.Number` + numpad** (3×4, вызов кликом по значению или стик-кликом):
   «320» = 4 клика, одна undo-команда; подключается к длине текущего сегмента стены,
   `Length` выбранной стены, Level/Thickness/Plan scale — всем существующим рядам.
   Полный флоу «стена ровно 320 см»: грип → стик-клик → 3-2-0-OK = 5 действий.
2. **A = Duplicate / offset-wall** (параллельная стена на отступе из numpad);
   **A-hold (0.4 с) = радиальное контекст-меню** выделения (Delete/Duplicate/Flip/Join).
3. **Стик-клик = предыдущий инструмент** — закрывает ~80% переключений Sel↔Wall без
   прицеливания в палитру.
4. **Quick-measure на hover** в Select: бейдж размера у ретикла из `Describe()` —
   без похода в Measure за одной цифрой.
5. **Poke-ввод по палитре** (кончиком правого контроллера, порог 1.5 см) — ray остаётся
   fallback; инспектор и сцена — только ray.
6. **Не рвать цепочку Wall** при случайной деактивации (восстанавливать `_lastNode`).

## Резерв под MEP-слои (заложить сейчас, чтобы не редизайнить)

Каноническая палитра слоёв (константы в Core/SetupAssets):
Structure **#9AA7BE** · Electrical **#FFC94D** · Heating **#FF7A5C** ·
Plumbing **#4DA6FF** · Interior **#E0A96B** · Blueprint **#8AD0C8** ·
Measurements **#9B7BFF**. Конвенции: **левая цветовая кромка 4 мм = принадлежность
слою** (бейджи, строки инспектора, чипы); высота палитры 0.16 → 0.20 (пустой третий
ряд под layer-чипы: свотч + eye-toggle, long-press = solo; solo = остальные 20% альфы);
`ITool.AccentColor` = цвет редактируемого слоя → ретикл/кнопка/заголовок инспектора
согласованы автоматически.

## Порядок внедрения

P0.2 (repeat+хаптика — часы, чистая логика) → P0.4 + P1.2 (день-два, меняют риг) →
P0.3 + P1.1 (ретикл-система) → P0.1 (BP5, поток Blueprint) → P1.3–1.7 → P2.
Правки, меняющие состав рига (ретикл, палитра, инспектор), — через SetupRig; чистая
логика (repeat, хаптика, семантика B) — обычная пересборка.
