# Проёмы (двери/окна) — спека нового инструмента

Статус: **данные и геометрия готовы, инструмента нет.** Модель `WallOpening`
(along-fraction, width/height/sill, IsDoor, SwingDir/HingeDir) + панелизация в
`Wall.TriangulateWithOpenings` (простенки, перемычка, откосы, стекло, рамы, полотно)
работают для IFC-импорта и персиста. Слот 4 радиала («Openings», иконка
`door-window`) — заглушка с null-инструментом (`ToolManager.cs:113`).

Дизайн-основа: `docs/design/03-openings.md`. Это Фаза D — самый ценный недостающий
инструмент: без него нарисованный вручную дом — глухая коробка.

## Как должен работать инструмент

### Активация и палитра
- Id `openings`, лейбл «Open», иконка `door-window` (уже в `IconPaths`), слот 4
  радиала становится выбираемым. Цвет слоя — тот же, что у стен.

### Схема настроек (SettingsSchema v2)
- **Tabs: Door | Window** (суб-режимы — только табами, `Cycle` запрещён).
- Страница Door: Numeric `Width` (дефолт 850, 600…1200 мм), Numeric `Height`
  (дефолт 2100), Segmented `Hinge: Left | Right`, Segmented `Swing: In | Out`.
- Страница Window: Numeric `Width` (дефолт 1200), Numeric `Height` (дефолт 1400),
  Numeric `Sill` (дефолт 900, 0…2000).
- Значения — дефолты следующего проёма (как у стен); за экземпляр — см. ниже.

### Постановка
1. Луч по стене (слой 6, только `SelectableKind.Wall`) → **ghost-превью** проёма:
   полупрозрачная рамка габарита на грани стены в точке прицела, центр по лучу,
   низ = sill (окно) или base стены (дверь). Магнит центра к середине простенка и
   к шагу сетки при включённом Grid.
2. Валидация live (цвет ghost'а): зелёный — можно, Danger — нельзя:
   - простенок до соседнего проёма/торца ≥ 5 см;
   - верх проёма ≤ высоты стены − 5 см (перемычка);
   - без пересечений с существующими проёмами.
3. Триггер → `OpeningCreateCommand` (undo): проём в `WallSegment.Openings` +
   `RebuildAround`. B — выход в Select.

### Выбор и редактирование
Проём должен стать выбираемым. Вариант реализации: лёгкий дочерний `Selectable`
(`SelectableKind.Opening`) с тонким box-коллайдером по габариту проёма (обновляется
при ребилде стены; сам меш не нужен — геометрия уже в стене).
- Selection-блок: «Door 850×2100» / «Window 1200×1400, sill 900».
- Per-instance схема (`OpeningParameters : ISettingsProvider`): Numeric Width/Height
  (+Sill у окна), Segmented Hinge/Swing у двери, Action «Delete» (Destructive) —
  все через before/after-команды `OpeningParamCommand` с той же валидацией.
- Ручки (через `IHandleProvider`): одна по центру — драг вдоль стены (позиция),
  две по бокам — ширина симметрично; снап к сетке; кламп по валидации; одна команда
  на жест.
- Перенос на другую стену — v2 (пока удалить/поставить).

### Интерактивное открывание двери
Угол уже параметризован (`DoorOpenAngleDeg`, константа 75).
- v1: у двери per-instance Toggle `Open` — полотно 0°/75° (поле `OpenDeg` в
  `WallOpening`, персистится; импортные двери получают 75 как сейчас).
- v2: Slider 0…100 % — «примерить, задевает ли дверь мебель».

### Персист и тесты
- Формат уже хранит всё нужное (`ProjectOpening`); добавить `OpenDeg`.
- Тесты: EditMode — валидация (простенок/перемычка/пересечения), пересчёт долей
  при сплите (см. [02-walls.md](02-walls.md) §Б1 — делать вместе); PlayMode —
  create/undo/redo, драг ширины рейкастами (сквозь проём/в простенок — паттерн
  `WallOpeningPlayTests` готов).

## Зависимости и порядок

1. Сначала [02-walls.md](02-walls.md) §Б1 (сплит теряет проёмы) — иначе инструмент
   будет расставлять проёмы, которые ломаются первым же T-стыком.
2. Разделение коллайдера стекла/тела ([02](02-walls.md) §Техдолг) — чтобы пик
   проёма не конфликтовал с пиком стены.
3. Инструмент по этой спеке (через `/new-feature`: дизайн-док `03-openings.md`
   дополнить ссылкой сюда, декомпозиция в чек-лист).
4. Ручки и Toggle Open — вторым коммитом.
