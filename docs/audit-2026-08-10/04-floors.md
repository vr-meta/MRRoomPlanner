# Полы (Floor) — аудит и план

Код: `Core/Polygon.cs`, `Core/Floor.cs`, `Floors/FloorController.cs`,
`Floors/FloorHandles.cs`, `Floors/FloorParameters.cs`.

## Текущее состояние (кратко)

Произвольный контур (замыкание кликом по первой точке / B при ≥3 углах), дыры
(контур внутри плиты автоматически становится дырой; мосты в `TriangulateWithHoles`),
ручки углов с undo, Thickness/Level за экземпляр, стены магнитятся к контурам плит,
план-UV сверху / метрические UV с боков и снизу, vertex-AO к контуру и дырам,
midpoint-подразбиение под градиент AO.

## Баги к исправлению

### Б1. `AddHole` молча уничтожает плиту (P0/B5)
`Floor.AddHole` определяет успех по `_holes.Count == holes.Count`, что истинно
всегда (список пополняется до триангуляции). Если мост к контуру не построился —
метод возвращает `true`, а меш становится пустым и коллайдер снимается: плита
невидима, неподбираема, но зарегистрирована.

**Как должно работать:** триангуляция — до коммита: построить `TriangulateWithHoles`
во временный буфер; если результат пуст/не построился — откат `_holes`, возврат
`false`, плита не тронута. `FloorController.CloseOutline` при `false` даёт
Danger-хаптику и не съедает нарисованный контур (оставляет превью — пользователь
поправит). Дополнительно `AddHole` отклоняет дыру, пересекающую существующую
(`Polygon`-пересечение колец). Тест: две пересекающиеся дыры → вторая отклонена,
меш жив.

### Б2. Драг угла перепекает коллайдер и AO каждый кадр (S4)
`FloorHandles.PreviewHandle` → `MoveCorner` → полный `BuildOutline`, который всегда
переприсваивает `MeshCollider.sharedMesh` и гоняет AO-подразбиение (до 4 итераций)
+ `DistanceToRingXZ` O(V·E). Комментарий в `FloorHandles.cs` утверждает обратное.
Нарушение правила 4.2 (стены делают правильно через `DeferCollider`).

**Как должно работать:** порт механики стен: `Floor.DeferCollider` на время жеста,
`RefreshCollider` один раз в `EndDrag`; на превью — облегчённый ребилд без
AO-подразбиения (плоский цвет 1.0), полный ребилд на коммите. Тест: PreviewHandle
N раз → sharedMesh переприсвоен 0 раз до EndDrag.

### Б3. Самопересечение при драге оставляет плиту без меша
`Polygon.IsSimple` отказывает → пустой меш до обратного драга.

**Как должно работать:** невалидная позиция превью — ручка красится Danger, контур
остаётся в последней валидной позиции («резиновый» отказ, как miter limit); в
`EndDrag` — коммит последней валидной. Плита никогда не исчезает.

## Развитие

### Р1. Undo создания плиты и дыры (S1)
`FloorCreateCommand` (плита) и `FloorHoleCommand` (дыра: Execute = AddHole,
Undo = RemoveHole — API уже есть, в UI не выведен). «Отменить последнюю точку»
контура при рисовании — B при >0 точек снимает последнюю (сейчас B сбрасывает всё
при 1–2 точках), Esc — двойной B.

### Р2. Снапы инструмента пола (S3)
Сейчас — только сетка. **Как должно работать:** точки контура прогоняются через
общий `SnapFinder`: узлы/грани стен → углы/рёбра соседних плит → сетка, с
уважением тумблеров панели (пункт «перевести FloorController» уже висит в B6
чек-листа). То же — в драге ручек углов. Кейс: плита точно по нарисованным стенам
без зазоров.

### Р3. Редактирование контура и дыр
- **Вставка вершины:** наведение на ребро выбранной плиты (в Select) показывает
  фантомную ручку на проекции курсора; триггер по ней = `FloorVertexInsertCommand`
  + сразу драг новой вершины.
- **Удаление вершины:** hold B на ручке (паттерн destructive-hold уже есть) при
  `Outline.Count > 3`.
- **Дыры:** ручки углов дыр (тот же `FloorHandles`, кольца дыр после контура);
  selection-блок показывает «Floor 17.3 m², 2 holes»; Action «Remove hole» у
  ближайшей к последнему пику дыры — или пик дыры как под-объект (проще: ручки +
  destructive-hold на ручке дыры = удалить всю дыру).
- Дыры участвуют в снап-кандидатах стен (`AddFloorSnapCandidates` дополняется
  кольцами дыр) — стены вокруг лестничного проёма.

### Р4. Наклонные плиты (пандусы) — v2, по запросу
`Level2`/уклон по направлению; не начинать без реального кейса — тянет за собой
пересмотр AO, стыков со стенами и телепорта.

## Техдолг

- `FloorController._floors` — параллельный источник правды рядом с `SceneModel`;
  `ImportController.ClearScene` оставляет в нём мёртвые ссылки. Убрать список,
  ходить через реестр (как сделали стены в B3b).
- `OutlineCopy`/`HolesCopy` на каждый ребилд — переиспользуемые буферы.
- Контракт `Polygon.Clean` (комментарий обещает удаление коллинеарных точек, код
  удаляет только дубли) — исправить комментарий или доделать код; на контракт
  опирается `Stair.Prism`.
