# Стены, комнаты, потолки — аудит и план

Код: `Core/WallGraph.cs`, `Core/WallMesh.cs`, `Core/Wall.cs` (~760 строк),
`Walls/WallController.cs`, `Walls/WallGraphRenderer.cs`, `Walls/WallHandles.cs`,
`Walls/WallParameters.cs`.

## Текущее состояние (кратко)

Граф узлов/сегментов с настоящими T-стыками (`SplitSegmentAt`), единый алгоритм
стыка любой степени (азимутальная сортировка, miter limit ×4), параметры за сегмент
(Thickness/Height/Offset/Side) с undo-командами, ручки узлов (одна команда на жест),
снапы к узлам/граням/контурам полов/углу/сетке, панелизация проёмов (простенки,
перемычка, откосы, стекло-submesh, рамы, дверное полотно; импортные двери открыты
на 75°). `FindClosedLoops()` написан и протестирован, но не вызывается.

## Баги к исправлению

### Б1. Сплит стены теряет проёмы (P0/B4)
`WallSegment.CopyParamsFrom` не копирует `Openings`, а `AlongFraction` остаётся
относительно старой длины → после T-стыка через стену с окном все проёмы прилипают
к A-половине с неверной позицией.

**Как должно работать:** при `SplitSegmentAt(t)` каждый проём пересчитывается:
доля `f` в старой стене → мировая позиция → принадлежность половине (сравнение с
`t`) → новая доля относительно своей половины. Проём, попавший на линию сплита
(пересекает `t`), запрещает сплит в этой точке — снап-кандидат на грани сдвигается
к ближайшему краю проёма (правило «мин. простенок» из [03-openings.md](03-openings.md)).
Тест: стена с окном на 0.7, сплит на 0.5 → окно на B-половине с долей (0.7−0.5)/0.5.

### Б2. Bevel/Round — UI без эффекта (P0/B8)
`WallMesh` нигде не читает `s.Join`; ряд «Corner» в `WallParameters` и настройках
инструмента ничего не меняет. Bevel/Round живы только в легаси-`Wall.Build`, который
в рантайме не вызывается.

**Решение (выбрать одно):**
- *Минимум (рекомендуется сейчас):* убрать ряд «Corner» из обеих схем и `Join` из
  UI-стора; в `02-walls.md` зафиксировать «стыки — всегда митра с лимитом». Поле в
  модели/персисте оставить (формат не ломаем).
- *Максимум:* реализовать Bevel/Round в `WallMesh.CornerPoint` для узлов степени 2
  (для 3+ митра остаётся) — фаска/дуга вставляется между пересечениями граней клина.
  Делать только при реальном запросе с устройства.

### Б3. Скрытая стена продолжает формировать стыки (P0/B11)
`DeleteCommand` скрывает view, но сегмент остаётся в графе → соседи по-прежнему
митрятся под несуществующую стену, узлы участвуют в `FindNode`.

**Как должно работать:** у `WallSegment` появляется флаг `Suppressed` (выставляет
`WallGraphRenderer` при hide/show своего view). `WallMesh` при сборке клина у узла
пропускает подавленные сегменты; `SnapOrCreateNode`/`FindNode` их не учитывают при
поиске, но узлы не прунятся (undo вернёт всё как было). `RebuildNeighbourhood`
вызывается при hide и show. Тест: L-угол, скрыть одну стену → у второй торец
становится плоским; undo → митра вернулась.

### Б4. Round-trip меняет топологию
`ProjectStore.ToBuilding` пересобирает граф через `SnapOrCreateNode` (толеранс 5 см)
→ узлы ближе 5 см сливаются после save/load.

**Как должно работать:** формат v2 сохраняет **id узлов** (уже стабильные) и рёбра
по id; загрузка восстанавливает узлы по точным координатам без снапа. Снап — только
для интерактивного рисования.

## Развитие

### Р1. Undo создания стены (S1)
`WallCreateCommand`: Execute = сегмент в граф + view + регистрация; Undo =
`Suppressed` + скрытие (см. Б3), Redo — обратно. Одна команда на **сегмент** (клик
цепочки), чтобы X откатывал по точке, как «отменить последнюю точку», которой сейчас
нет. Заодно закрывается P0.3 из UX v2 (авто-выбор стены после FinishChain).

### Р2. Снапы в драге узлов (S3)
`SelectController` тянет ручку узла по `RayPlaneY` без сетки и магнитов.
**Как должно работать:** превью ручки прогоняется через тот же `SnapFinder`
(углы соседних стен/плит → рёбра → сетка), уважая тумблеры панели снапов. Если
отпустили узел поверх другого узла (в пределах 5 см) — **слияние узлов** отдельной
командой `WallNodeMergeCommand` (все рёбра переезжают на выживший узел, дубликаты
рёбер схлопываются). Это даёт замыкание контуров перетаскиванием — прямой путь к
комнатам (Р4).

### Р3. Редактирование высоты и BaseHeight
- Ряд Numeric «Base height» в `WallParameters` (поле уже в модели и импорте).
- Ручка высоты: при выбранной стене — одна ручка на середине верхней грани, драг
  по вертикали (`RayPlaneY` заменяется вертикальной плоскостью, перпендикулярной
  взгляду), с шагом сетки при включённом Grid; команда before/after.

### Р4. Комнаты (F3)
Вся математика готова: `WallGraph.FindClosedLoops()` + `Polygon.AreaWithHoles`.

**Как должно работать:**
- `RoomRegistry` (Core): после каждого изменения графа (событие уже есть —
  `GeometryChanged`) пересчитывает кольца; кольцо → `Room` с контуром по **внутренним**
  граням стен (offset от осевой с учётом Thickness/SideSign), площадью и центроидом.
- Визуал v1: полупрозрачная подсветка контура комнаты при наведении в Select +
  Readout «Room: 17.3 m²» в selection-блоке; бейдж площади в центроиде (как бейдж
  рулетки), тумблер «Room labels» на странице Rendering.
- Комнаты — **производные данные**: не персистятся, не выбираются как объекты (v1),
  пересчёт ленивый (по флагу грязности, не каждый кадр).
- Потребители: покраска «всей комнаты» ([06](06-paint-textures.md) §Р2), потолки (Р5),
  спецификации, AI Placement (комната = контекст запроса).

### Р5. Потолки (F4)
Класса нет вовсе; «потолок» существует только как нормаль в электрике.

**Как должно работать:** `Ceiling` = та же `Floor`-плита (переиспользуем меш/дыры/AO),
но построенная по контуру комнаты на высоте `min(Height)` её стен, винда вниз.
Создание: кнопка «Add ceiling» в selection-блоке комнаты (после Р4) либо
авто-генерация тумблером на комнату. Красится как обычный `Selectable` (категория
Ceilings в Paint), персистится как `ProjectFloor` с флагом `IsCeiling`. Свет из
[06](06-paint-textures.md): потолок закрывает skybox → проверить ambient в Scan OFF.

## Техдолг (без изменения поведения)

- Легаси-путь `Wall.Build`/`BuildFootprint` живёт только ради тестов — пометить
  `[Obsolete]`, тесты перевести на графовый путь, затем удалить (вместе с Б2-минимум).
- Коллайдер стены включает стекло и открытое полотно двери → луч/телепорт упираются
  в стекло. Разделить: коллайдер тела из submesh 0; стекло/столярка без коллайдера
  (или отдельный тонкий для пика двери — понадобится Openings-инструменту).
- `TriangulateWithOpenings` аллоцирует списки на каждую перестройку; драг узла стены
  с проёмами делает это покадрово — кэшировать буферы (правило «ноль аллокаций в кадре»).
- `WallController._floorCache` инвалидируется по `Items.Count` — заменить на версию
  реестра (`SceneModel.Version++` при Register/Unregister).

## Порядок работ

1. Б1 + Б3 (целостность графа) → сразу тесты.
2. Б2-минимум (убрать мёртвый Corner из UI).
3. Р1 (undo создания + отмена последней точки).
4. Р2 (снапы драга + слияние узлов).
5. Р4 (комнаты) → Р5 (потолки) — отдельная фича по скиллу `/new-feature`.
6. Б4 — вместе с форматом v2.
