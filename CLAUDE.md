# CLAUDE.md — правила работы над проектом

**Обязательно:** вести работу строго по чек-листу — [`docs/CHECKLIST.md`](docs/CHECKLIST.md).

## Правила

1. Перед началом задачи — свериться с `docs/CHECKLIST.md`: что уже сделано, что нет.
2. Держать чек-лист в актуальном состоянии: `[x]` выполнено, `[~]` в работе, `[ ]` не начато.
3. Если задача начата, но не завершена — **разбить её на под-задачи** и отмечать их по
   мере готовности. Не оставлять крупную задачу «наполовину» без декомпозиции.
4. Технические/архитектурные решения — в [`docs/design/`](docs/design/README.md). При
   реализации следовать им; при изменении решения — обновлять соответствующий документ.
5. **Решённые проблемы окружения фиксировать** в чек-листе (раздел «Решённые проблемы»),
   чтобы не наступать на них повторно.

## О проекте

MR-приложение для Meta Quest 3/3S (Horizon OS): скан помещения и работа с интерьером —
рулетка, покраска/текстуры, стены, проёмы, мебель через AI, инженерные сети, обмен
форматами (IFC/DWG/glTF). Клиент — Unity 6 (6000.0.81f1) + C#; база — сэмпл **Virtual
Home** (MRUK). Верхнеуровневая карта — [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Сквозной принцип

Геометрия и отделка — **параметрические данные**, меши/материалы генерируются
процедурно. Без CSG-объединений и «запечённых» развёрток. См. `docs/design/00-overview.md`.

## Пересборка приложения (важно)

- Изменена **только логика** внутри существующих скриптов → достаточно **Ctrl+B** (Build And Run).
- Изменён **состав рига** (новые компоненты/сериализованные поля/префабы) → сначала
  **RoomPlanner → Setup Measure Rig** (пересоздаёт риг и связывает ссылки), затем **Ctrl+S**, затем **Ctrl+B**.
  Просто Ctrl+B **не дозаполняет** новые сериализованные поля в уже существующем объекте сцены.
- В ответах пользователю **всегда явно указывать**, нужен ли повторный Setup или хватит Ctrl+B.
- Проверка, что новый билд доехал: в `adb logcat` строка вида `[Measure] vN started ... contBtn=True`.

## Окружение (Windows)

- Диск **C: почти полон — всё ставить на D:**:
  - редакторы Unity — `D:\Unity\Editors`
  - инсталляторы — `D:\Installers`
  - TEMP для установок — `D:\Temp`
- Unity Hub — MSIX (виртуализирует TEMP на C:), поэтому редакторы ставим **офлайн-
  инсталляторами** Unity, а не через Hub. Детали — в `docs/CHECKLIST.md` → «Решённые проблемы».
